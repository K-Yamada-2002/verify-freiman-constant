Berstein の Hall's ray より下の区間：数学・実装の独立監査
2026-10-01

監査対象
  [4.52578, 4.52754] ⊂ M ∩ (-∞, c_F)
  c_F = (2221564096 + 283748√462)/491993569.
  固定語は a=322, b=431、中心数字は4、追加数字は1,2,3、禁止語は31313。

判定
  以下の数学的論証と、有限証明書の独立した全行検証に基づき、この区間包含は
  正しい計算機援用証明になっていると判断する。監査範囲に致命的欠陥はない。
  前回の監査で残っていた「大規模被覆判定を別実装では検証していない」という
  留保は、今回の独立検証器による全3,464,816行の成功によって解消した。
  公開文献上の未解決問題に対する新結果に当たるという位置付けは変わらない。
  131禁止集合の和の内点や、[4.1,4.52]⊂L という Berstein 予想全体の証明ではない。

1. 検証系の独立性と役割分担

  independent_input.py
    元の Python モジュールを一切 import しない。独自の Q(√462) 演算、
    禁止語の直接検査、周期連分数の固定点計算で .dat の数学的意味を検証する。
    元の状態表 .alive.bin は、採用する有限族を指定するデータとしてだけ使う。

  independent_kernel.cpp
    元の C++ 検証器を include/呼出ししない。独自の整数区間演算と
    disjoint-set による連結性検査を実装した。浮動小数を一切使用しない。
    全子頂点を保持し、元の「front の8候補への切捨て」を使用しない。
    両方向の端点比較、または同じ親の分割点を含むことによって辺を証明する。
    端点差について二通りの正負係数の組合せから得た外側評価を交差させる。
    保存された有限族を固定し、一行でも失敗すれば非ゼロ終了する。

  independent_spectral.py
    元のモジュールも independent_input.py も import しない。
    Fraction と64桁の合法極値接頭語、終端 [0,1] だけで外側評価する。
    7桁窓による bulk の上界、固定部、近傍の全中心、遠方の誤差を検証する。

  check_independent_kernel.py
    穴、片端の欠落、子の状態の欠落、子の比が移る先の箱の欠落を含む
    人工証明書を作り、誤った被覆を検証器が拒否することを調べる。

2. 連分数と端点の数学的意味

  F_a(x) = [0;a_1,...,a_n+x]
         = (p_{n-1}x+p_n)/(q_{n-1}x+q_n),  r=q_{n-1}/q_n.
  行列式は (-1)^n。したがって偶数長では増加、奇数長では減少する。

  合法な数字を一つ選んだ後は、2を無限に続ければ必ず無限延長できる。
  よって、連分数の交互辞書式順序による貪欲な極値選択は正当である。
  禁止語接頭語でもある最長末尾と偶奇を状態にすれば、極値尾は最終的に周期的。
  独立入力監査では周期行列の二次方程式を解き、唯一の正の固定点を確認した。

  固定語431の4は合法。追加数字を1,2,3に制限することと矛盾しない。
  元の記述は「固定語にも4禁止を課す別の集合」と明確に区別している。
  形状箱の前史 [1/4,4/5] に対し、431の前史は1/4、322の前史は1/3。
  根が箱の閉じた境界に来ることにも問題はない。

  同一の raw endpoint ID を相殺する処理は重要な信頼境界である。
  独立入力監査は、各参照の真の代数的端点を再計算し、IDの共有が厳密な
  同一性を意味することを確認した。近似値が一致しただけでは相殺しない。

3. 箱全体での端点比較

  ξ_a を F_a の下端を与える尾とし、D_a=|F'_a(ξ_a)| とする。
  D_a = 1/[q_n²(1+rξ_a)²] であり、直接計算から

    (F_a(x)-F_a(y))/D_a
      = (-1)^n (x-y)(1+rξ_a)²/[(1+rx)(1+ry)].

  子の部分区間の端点は、子の全円筒の両端の凸結合である。
  二つの端点式の差は係数和が0なので、正係数と負係数を対応させて
  正の質量×上の差の和に分解できる。
  各分解は同じ真の値を表すから、複数の外側評価の交差も正当な外側評価。
  (1+rξ_a)/(1+rx) は正で、固定した真の ξ_a,x に対し r の一次分数。
  箱の両端での区間評価は全範囲を囲む。尾同士の相関を捨てても過小な
  外側区間にはならず、不等式を証明できなくなる方向にだけ影響する。

  右側の正規化係数 S=D_b/D_a は正である。左の差を A、右の差を B とすれば、
  A+S B の下界が0以上の時だけ、対象の端点不等式を採用する。
  独立実装は積を128ビット整数のまま比較し、表示用小数を判断に使わない。

4. 後続の状態と微分比

  追加語 u の行列を (α β; γ δ)、子の下端尾を η とすると、

    r' = (γ+rα)/(δ+rβ),
    D_{au}/D_a = [(1+rξ_a)/(γη+δ+r(αη+β))]².

  分母は正。平方前の正の一次分数は単調または定数であり、箱の両端で
  全体を評価できる。左右にそれぞれ u,v を追加した時は

    S' = S × (D_{bv}/D_b)/(D_{au}/D_a).

  この向きは元のコード・独立コードともに一致する。
  子の形状の像は指定した子の形状箱に含まれることを全遷移で検証した。
  子の S' を含む連続した比の箱すべてで、使う区間型の採用を要求する。

  同じ定数IDなら S'=S とする短縮処理も検証した。定数性の正確な条件は

    ξ_a(γη+δ) = αη+β.

  各タグでこの恒等式を確認し、さらに同じIDの異なる遷移が厳密に同じ
  微分倍率を持つことを確認した。丸めた倍率の一致を理由にはしていない。

5. 連結グラフから被覆への量化

  二つの閉区間 I=[l,u], I'=[l',u'] が交わるには u≥l' と u'≥l の両方が必要。
  両検証器ともに箱全体でこの二方向を証明してから辺を採用する。
  採用した同じ辺が箱内の全パラメータで成立するため、連結成分の区間和は
  各パラメータで連結である。その成分の一つの区間が親の左端より左に達し、
  別の区間が親の右端より右に達すれば、親全体を覆う。両端の担当が違ってもよい。

  独立実装が追加した「同じ親の分割点を含む」辺も、その実際の点が両方の
  区間に入ることを二方向で証明しているため正当である。

  元の浮動小数による候補順序・除外や8候補への切捨ては、証明済みの辺を
  捏造しない。見落としの可能性を増やすだけで、偽の被覆を正当化しない。
  二分探索で不等式判定の成功が数値的に単調とは限らなくても、保存した
  閾値自体は実際に検証済みであり、真の親端点は分割座標について単調。
  そのため、採用された端点条件の正当性は保たれる。

6. 有限族の閉性から Cantor 和へ

  任意の t∈J_{p,q}(a,b) を固定する。被覆によって t を含む許容子を選ぶ。
  子の型は実際のパラメータの箱でも許容的なので、同じ操作を反復できる。
  全後続で |u|+|v|>0 が確認されているため、総語長は無限に増大する。

  全表で (51/50)^(-155) ≤ S ≤ (51/50)^155。
  0≤r,s,ξ_a,ξ_b≤1 から 1/4≤S/(q_a/q_b)²≤4。
  よって q_a/q_b は正の上下界を持ち、片側だけが無限に伸びることは不可能。
  両側とも語長が発散し、連分数円筒の幅は0に収束する。

  補助の部分区間が親の部分区間に含まれる必要はない。
  各段階で t が対応する基礎円筒の和の凸包に入り、その基礎円筒が接頭語の
  延長により入れ子で縮むことを使う。極限の二つの無限語は31313を避け、
  それらの連分数の和が t になる。これで凸包と実際の和の区別を埋められる。

7. 初期語と Markov spectrum への移行

  独立に計算した根の値は r=7/17, s=13/17, q_a=q_b=17。
  S=(55792801+2467176√462)/159491641 は指定された第-20箱に入る。
  根の25帯の和は J_{1/16,7/8}(322,431)。その中心4を加えた区間は

    [4.525777278415714..., 4.527546990114258...].

  文書に記載された全凸包端点 L,H と S の式も、独立代数計算で完全一致した。
  端点と目標の有理区間、c_F の順序は厳密演算で確認した。

  Markov 値は中心値だけでは決まらないので、全非中心値の支配を別に検証した。
  元の実装と別に、合法な7桁窓2,161個の全列挙で bulk 上界を得た。
  固定部の非中心6箇所と、固定部の外側1～9桁にある全57,054中心を評価した。
  元の実装で省略する数字1,2や隣接数字による簡易判定も、今回は省略していない。

  さらに遠い中心では、中心方向の最初の9桁を残し、残りを222...に置換する。
  禁止語は31313なので、この接合で新たな違反は生じない。
  他方の半列はそのままにでき、置換後は全体が1,2,3の合法列になる。
  置換誤差は9桁の連分数円筒幅以下で、q_9≥55 より高々1/3025。
  これによって全非中心値が一様に

    4.525422212239697... < 4.525423 < 4.52578

  と評価される。従って構成された中心値はその二側列の supremum であり、Mに属す。
  さらに独立の代数クラスで合法な5桁窓を再計算し、bulk の最大値が厳密に
  4√462/19 であることと、近傍・固定部の有理上界が文書の厳密な
  Θ=4√462/19+1/3025 より小さいことも確認した。

9. 監査範囲

  これは表示された小数点、有限個の標本値、探索の成功フラグに依拠する結論ではない。
  有限表の全行で箱全体を覆う不等式を確認し、その有限命題から上記の解析的議論で
  無限語とスペクトルの包含を導いている。

  width と eta の補助入力は、対象 graph 検証器の被覆判定では使われない。
  width は読み出されない actual_ratio 配列の計算に、eta は読込みにだけ使われる。
  したがって、それらの別用途の数学的意味は今回の結論の依存先に含めていない。
  Freiman フォルダーの他の半直線証明や、131禁止の別の探索の正しさは結論しない。

  今回追加した独立C++検証器のレビューでは、最後の端点IDを欠いた入力を
  明示的に拒否する stream 状態の検査を補強した。元の証明コードの欠陥ではない。
  対象 .dat は完全であり、Pythonの独立入力監査でも欠落を拒否するため、
  この補強は実際の証明書の数学的判定を変えない。最終版で再検証した。

    c++ -std=c++17 -O2 -fsanitize=undefined -fno-sanitize-recover=all \
        Berstein/audit/independent_kernel.cpp -o /tmp/berstein-independent-kernel

        Freiman/data/graph_wide.json.alive.bin
