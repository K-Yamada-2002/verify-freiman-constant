## 今回の結果（2026-09-24）

195,000 接頭語対を検査し、支配条件を満たして対象範囲と交わるものは 11,220 組。
そこから選別した 165 件の全てを追加検査し、**139 件が全検査を通過**、26 件は未通過。
被覆検査は計 495 回のうち 433 回が数値的に被覆、62 回が数値的に不被覆、予算超過は 0 回。
点近似は 3,465 点中 3,434 点で誤差 `10^-30` 未満の表示を得て、有理数で再検証した。
31 点は探索で表示が得られず未確定。所要時間は約 53 秒。9 テスト通過。

通過した固定区間の位置は約 4.19288 から 4.51484 に分布する。
この範囲全体を覆うという意味ではなく、4.1 付近や 4.52 までの全域も未検証。
同じ集合の異なる円柱、包含関係にある集合、重なる区間を含むので、
139 件を独立した現象や互いに素な区間の数とは解釈しない。

特に元の `K_F` と異なる集合を使う例は次の通り。
`A = K_{123,{1312,1313,2131,3131}}`,
`B = K_{123,{1313,3131}}`, `C12 = K_{12,∅}` と書く。

## 何を探すか

数字集合 `A ⊆ {1,2,3}` と有限禁止語集合 `F` から

\[
K_{A,F}(u)=\{[0;a_1,a_2,\ldots]: a_i\in A,\ F\text{ の語を含まず、}a_1\cdots a_{|u|}=u\}
\]

を作り、`3 + K_{A,F}(u) + K_{B,G}(v)` の内点候補を探す。
左右の接頭語は**ともに中央の 3 から外側に向かって**読む。
両側列として中央付近は `… reverse(u) 3 v …` になる。
同一集合の和と異なる集合の和を両方調べる。
禁止語有限型の Gauss–Cantor 集合とその円柱を対象とする。

Berstein 予想の対象が `[4.1,4.52] ⊂ L` であることは
[Delecroix–Matheus–Moreira, Approximations of the Lagrange and Markov spectra](https://pure.mpg.de/rest/items/item_3254907_2/component/file_3254908/content)
を参照。ここではその一部分の候補を列挙し、予想の証明は主張しない。

`catalogue()` は 13 モデルを指定する。これは全 Gauss–Cantor 集合の網羅探索ではない。
数字 4、非対称禁止語、任意のブロック IFS は今回の範囲外。
`F31313`, `F13131`, `C123` も比較対象に含めるが、今回の背景上界では
4.52 より下への一様な帰着ができないので、組の探索から除外される。
これは、それらの集合で別の帰着が不可能という意味ではない。

`C12` や禁止語に `131` を含むモデルは `K_F` の部分集合であり、
その和の内点を示せば `K_F+K_F` の内点も示せる。
一方、`F1312` と `F1313` は `131` 自体を許し、元の集合とは異なる候補を与える。
部分集合間の多数の候補は独立の現象として数えない。
文献上の新規性も主張しない。

## Lagrange スペクトルへの帰着条件

単に和の区間を探すと、中央以外の局所 Perron 値の方が高くなる場合がある。
そこで今回の候補には次の十分条件を課す。

1. 禁止語は反転対称。全てのオートマトン状態から合法な有限語で周期 `222…` に接続できる。
2. 半径 `r` の**全ての合法な**長さ `2r+1` の窓 `w` について、
   `w[r] + [0; reverse(w[:r]), tail] + [0; w[r+1:], tail]` の上界を列挙する。
   未知の尾部は `[1/4,4/5]` で囲う。最大値を `H_A`, `H_B` とする。
3. `|u|=|v|=r` とし、中央から距離 `1,…,r` の非中央位置も検査する。
   数字 1,2 の値は常に `18/5` 以下。
   例えば `u[k]=3` の位置なら、両側に既知の語
   `u[k+1:]` と `reverse(u[:k]) + 3 + v` を使い、同じ尾部区間で評価する。
   この最大値を `H_near` とする。
4. 候補区間の下端が `H = max(H_A,H_B,H_near)` を厳密に上回ること。

背景と中央近傍の上界は **Fraction による有理数演算**で計算する。
モデルの周期 2 への接続語も JSON に保存する。
尾部区間が全ての 123 連分数を含むことは
`1/(3+4/5) ≥ 1/4`, `1/(1+1/4) ≤ 4/5` から従う。

この条件の下では

\[
(3+K_{A,F}(u)+K_{B,G}(v))\cap(H,\infty)\subset L.
\]

**理由。** 目標値の左右の尾部を長さ `n` まで切り出し、中央の 3 を挟んだブロックを作る。
各ブロックの両端は、保存した合法な接続語で十分に長い 2 の列へつなぐ。
左側は反転対称性を使って同じ接続を逆向きに用いる。
長さを増やしたブロックを長い 2 の列で連結した片側無限列を作る。
接続部をまたぐ半径 `r` の窓は、2 の列を十分長く取れば、どちらか一方の合法な系の窓になる。
中央から距離 `>r` の位置は背景上界で、距離 `≤r` の位置は中央近傍上界で評価できる。
中央以外の局所値は一様に `H` 以下。中央の局所値は指定した和へ収束する。
したがってその limsup は目標値になる。
有限の左端による違いも、中央からの距離を増やすことで消える。

この帰着と、和に区間が含まれるかどうかは別の問題である。
**未解決なのは後者の無限スケールの包含。**

## 数値探索の段階

- 各系の禁止語接頭辞から有限状態オートマトンを作る。
  尾部の最小・最大は `x → 1/(a+x)` の単調性を用い、全状態で同時更新する。
- 長さ `r` の合法な接頭語対を列挙する。背景条件で棄却したモデル対は列挙数に含めない。
  同一モデルでは左右交換をまとめる。
- 各側に 2 桁追加した円柱の全和凸包を合併する。
  対象範囲と支配条件で切り取り、0.02 ごとの帯域の中から幅の大きな候補を残す。
  各モデル対に `--per-pair` 件まで残すので、候補の完全列挙ではない。
- 追加深さ 3,4,5 と細分し、前段の成分内で最大の成分を追跡する。
  最後の幅と、最初の幅に対する保持率で順位を付ける。
- モデル対の種類を優先して `--verify-count` 件を選ぶ。
  その後は順位順で追加する。
  各成分中央に幅最大 `2×10^-5` の**固定した**小区間を取り、
  最大和凸包幅 `10^-6`, `10^-7`, `10^-8` の各解像度で全区間を検査する。
- 各固定区間の両端を含む等間隔 21 点で、誤差 `10^-30` 未満の和の近似表示を探す。
  探索は Decimal、成功した表示は合法な周期 2 の末尾を持つ。
  100 個の 2 を展開した後の尾部を `[1/4,4/5]` で挟み、
  **後ろから評価する独立の有理数計算**で誤差を確認する。

浮動小数点の被覆検査には穴を埋める許容誤差を加えないが、
それでも丸め誤差を保証した区間演算ではない。
`covered_float` は数値的な成功、`gap_float` は数値的な不被覆、
`budget_exhausted` は未完了。後二者を不存在の証明として扱わない。
点の有理数検証は近似表示の誤差だけを保証し、目標点そのものの所属は保証しない。
区間内部を動かして成功箇所を探す段階と、固定した区間を検査する段階は分けて記録する。

候補の優先順位は証明の容易さや成功確率を表さない。
特に全体の和の外側近似と点サンプルだけから内点を結論しない。

## 再実行

リポジトリのルートで実行する。

```sh
python3 Berstein/pair_search/search.py --verify-count 165
python3 Berstein/pair_search/search.py --replay Berstein/pair_search/results.json
python3 -m unittest discover -s Berstein/pair_search -v
```

`--radius`, `--per-pair`, `--verify-count`, `--epsilons`, `--budget`,
`--points`, `--point-budget`, `--exponent`, `--window-width`, `--output` で探索範囲を変更する。
新しい禁止語モデルは `catalogue()` に追加できる。
`--radius` を大きくすると背景上界が鋭くなる一方、窓の列挙は指数的に増える。
`results.screen.json` は高精度の追加検査を始める前の候補一覧。

テストは既知の `K_F` の閉形式極値との比較、行列と有理数の後向き評価の照合、
禁止語と接続語、子円柱の包含、小さい穴を保存する区間合併、予算超過、
既知候補の高精度表示、不正な表示の拒否を検査する。
