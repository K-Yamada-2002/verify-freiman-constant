# [4.1, 4.52] 全域を対象にした集合対の探索

**最新：[包含候補を10本に削減](REDUCED_COVER.md)。** 7種類の基本集合を使い、10本それぞれを単独の和として有限精度で再検査した。

**全域を覆う有限スケールの候補族を得た。区間包含・Berstein 予想の証明ではない。**

- 87 個のパラメータ設定を使用。実際に異なる記号的遷移グラフは **15 種類**。
- 各設定の円柱対の記録は計 **2,607 件**。設定間の重複を含む。
- 円柱対に割り当てた有限近似の成分は 3,293 件。その合併は両端を含めて `[4.1,4.52]`。
- 採用した和凸包 **1,313,348 個**を有理数で囲い直した。その合併にも未被覆部分はない。
  最大幅は約 `9.999993292847964 × 10^-7 < 10^-6`。
- 等間隔 421 点と修復区間の端点・中点を合わせた **556 点すべて**で、誤差 `10^-30` 未満の合法な周期末尾の表示を構成し、有理数で再検証した。
- 14 テスト通過。

これは単一の和が全域を埋めるという結果ではない。
複数の集合の円柱対の和を合併する構成である。
各担当範囲について対応する円柱対の和の**合併**への包含を証明できれば、全域の包含が従う。
枝の有限スケールでの分担を、そのまま無限の表示選択として固定してよいとは主張しない。

## 集合の定義：目標の値から禁止語を作る

`D ∈ {3,4}`、半径 `r`、有理数 `H` を指定する。
今回の保存した全設定は `D=4`。
未知の連分数の尾部を

\[
I_D=[1/(D+1),(D+1)/(D+2)]
\]

で囲い、長さ `2r+1` の語 `w` に対し、有理数

\[
U(w)=w_r+\max_{x\in I_D}[0;w_{r-1},\ldots,w_0,x]
             +\max_{y\in I_D}[0;w_{r+1},\ldots,w_{2r},y]
\]

を計算する。ここで末尾の `x,y` は部分商ではなく、Möbius 写像に入力する完全尾部の値を表す。
**`U(w) ≤ H` の窓だけを許す**有限型のシフトを作る。
長さ `2r` の状態を持つ de Bruijn グラフのうち、`2^(2r)` を含む強連結成分だけを使う。
そのグラフの片側無限パスから得る Gauss–Cantor 集合を `K(D,r,H)` とする。
初期の `2r` 桁はこの成分の状態、以後の各桁はこの成分内の辺に従う。
`K(D,r,H;u)` は、その接頭語 `u` を指定した円柱である。

異なる `H` でも許容グラフが変わらなければ同じ集合になる。
87 設定が 15 グラフに縮約されるのはこのため。
グラフの各状態から `2^(2r)` への接続語を逆向き BFS で構成する。
窓の条件は反転対称であり、この強連結成分も反転対称なので、左右両側を周期 2 の列で接続できる。

探索は中央の 3 と 4 の両方を試したが、今回採用した円柱対の中央は全て **3** だった。
数字 4 を加えたこと自体を、改善の原因とは主張しない。
主な改善は目標値に応じた禁止語の自動生成と、未被覆部分を優先する探索である。

## Lagrange スペクトルへの帰着

集合内の半径 `r` の全ての窓の Perron 値は、定義から `H` 以下。
中央の例外的な数字 `c` に隣接する距離 `1,…,r` の位置は、
接頭語 `u,v` と、その終状態の尾部の上下界で別に検査する。
尾部の有理数の上下界は全状態で min/max の漸化式を 12 回反復して得る外側評価。
近傍の全ての値も `H` 以下である円柱対のみ採用する。
1,2 の位置は `2+2(D+1)/(D+2) < 4.1` 以下なので自動的に対象より低い。

このとき前の [帰着の議論](README.md#lagrange-スペクトルへの帰着条件) と同様、

\[
\bigl(c+K(D,r,H;u)+K(D,r,H;v)\bigr)\cap(H,\infty)\subset L.
\]

有限語の切り出しを周期 2 への合法な接続語でつなぎ、中央以外を `H` 以下に保ったまま、
中央の値を所望の和へ収束させる。これは、和に区間があるという未証明の主張を使わない。

## 探索と隙間の修復

全域を幅 0.01 の 42 個の区間に分け、各下端より `10^-5` 低い `H` と半径2を用いた。
各和凸包の幅が `10^-6` 以下になるまで分割し、全ての表示候補を保持した。
既に葉の和凸包で覆った範囲だけを、その解像度に限って省略した。
接頭語対の上位数件だけを採用する制限も、幅 `2×10^-5` の小区間に限定する制限も外した。

|段階|未被覆部分|処置|
|---|---:|---|
|半径2、全42区間|43個|対象長の約99.941%を有限近似で被覆|
|残りを半径3で修復|2個|各隙間に合わせて `H` を取り直す|
|残りを半径4で修復|0個|全域の有限スケール被覆|

最後まで残った2つの隙間は、約

- `(4.236891892119, 4.236891905486)`
- `(4.236892769243, 4.236892769700)`

だった。半径4では両方が覆われた。
全設定・全接頭語対を保存しており、元の13モデルの探索結果は上書きしていない。

## 有理数による全区間の検査が保証すること

発見段階の浮動小数点の被覆だけでは、微小な隙間を丸めで消す危険がある。
そこで `--rational-leaves` では、採用する各葉の2つの円柱を、
有理数の尾部区間と整数係数の Möbius 写像で再評価し、
**閉区間全体の有理数での合併**を別に計算する。
その合併が `[4.1,4.52]` を覆うことも確認した。

各葉の円柱は合法な周期末尾に延長できるので空ではなく、実際の和の点を含む。
各有理数の和凸包の幅が `ε < 10^-6` なので、
そこに属する目標は実際の和の点から距離 `ε` 以下にある。
担当区間の下端と `H` の差が、採用葉の最大幅より大きいことも有理数で確認した。
従って選んだ実際の和の点は `H` より大きく、上の帰着により `L` に属する。

今回の実行で得た有限精度の結論は

\[
\sup_{t\in[4.1,4.52]}\operatorname{dist}(t,L)
\le \varepsilon_{\max}<10^{-6}.
\]

これは計算過程での有理数評価と上の数学的帰着に基づく結果であり、形式証明ではない。
JSON は葉の合併と最大幅を保存し、130万個の個々の葉までは保存しない。
したがって、保存集約値の `--replay` だけでは全葉の検査を再現しない。
全葉を再検査するには下記の3段階の探索を `--rational-leaves` 付きで再実行する。
点の近似表示556件と、全ての根の支配条件は JSON から独立に再検証できる。

## 本質的な障害はあるか

**今回の探索から、この「Gauss–Cantor 集合の和を合併する」方針自体が全域を覆えないという障害は見つからなかった。**
むしろ固定の禁止語リストと候補の強い間引きが、前回の大きな未被覆部分の主因だった。

ただし「障害がないことを証明した」とも言えない。
次の区別が重要である。

1. **固定した探索設定の限界。** 半径2の族には残る隙間があった。半径3,4の別の族で有限精度では埋められた。
   ある一つの系・半径・支配条件の失敗を、全手法の不可能性とは解釈しない。
2. **証明上の未解決点。** 有限スケールの被覆を、全てのスケールで維持する帰納・再帰構造は未構成。
   今回も `K_F+K_F` と同じ種類の難しさが残る。有限距離の評価や点近似から区間包含は従わない。
3. **単純な十分条件の限界。** 厚みの積など、一つの十分条件が失敗しても和の内点不存在は従わない。
   今回は厚みの条件で候補を除外していない。

次に証明を狙う対象は、全2,607記録を個別に固定した表示へ分解することより、
15種類のグラフの各担当域について、複数の表示を保持する被覆規則を作ることである。
それらの有限な帰納が閉じれば全域の証明につながるが、**その閉包は今回未取得**。

有限近似と区間包含の区別については、
[Delecroix–Matheus–Moreira の有限精度近似アルゴリズムの論文](https://pure.mpg.de/rest/items/item_3254907_2/component/file_3254908/content)
も関連する背景資料となる。今回のプログラムはその実装や同論文による今回の数値の検証ではない。

## 再実行

Python 標準ライブラリのみ。リポジトリのルートから実行する。

```sh
python3 Berstein/pair_search/target_cover.py --epsilon 1e-6 --budget 1000000 --rational-leaves --output Berstein/pair_search/target_r2_rational.json
python3 Berstein/pair_search/repair_target_cover.py --input Berstein/pair_search/target_r2_rational.json --output Berstein/pair_search/target_r3_rational.json --radius 3 --rational-leaves
python3 Berstein/pair_search/repair_target_cover.py --input Berstein/pair_search/target_r3_rational.json --output Berstein/pair_search/target_complete.json --radius 4 --rational-leaves
python3 Berstein/pair_search/verify_target_cover.py
python3 Berstein/pair_search/verify_target_cover.py --replay Berstein/pair_search/target_audit.json
python3 -m unittest discover -s Berstein/pair_search -v
```

`--epsilon` を下げる場合は、3段階で同じ値を指定する。
`--budget` 到達と丸め精度の限界は不成功・未確定として記録し、被覆成功と混同しない。
全域被覆は今回保存した実行の結果であり、任意の精度での成功をプログラムが保証するものではない。
