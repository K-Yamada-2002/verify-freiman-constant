## 1. 全円柱に一様な厚みの上界

**命題。** 空語を含むすべての合法な有限語 `U` について、Newhouse の厚みは

\[
\boxed{\tau(K_F(U))\le\frac{19-5\sqrt{10}}4
 =0.797152924789525835\ldots<\frac45.}
\]

したがって、どの二つの全円柱を選んでも
`τ(K_F(U)) τ(K_F(V)) > 1` という標準的な Gap Lemma の十分条件は満たせない。
これは内点不存在の証明ではなく、任意の部分 Cantor 集合への上界でもない。
厚みは包含に関して単調とは限らない。
厚みと Gap Lemma の定義は、例えば
[McDonald–Taylor の論文](https://arxiv.org/abs/2111.09393) を参照。

### 証明

状態を `0`（空接尾辞）、`1`、`13` とする。尾部集合の凸包はそれぞれ

\[
[a,b],\quad[c,b],\quad[a,d],
\]

\[
a=\frac{2\sqrt{10}-5}{5},\quad
b=\frac{2\sqrt{10}-4}{3},\quad
c=\frac{\sqrt{10}-2}{4},\quad
d=\frac{2\sqrt{10}-5}{3}=\frac1{2+a}.
\]

連分数の交代順序で許される最小／最大数字を選ぶと、状態と偶奇の組が有限なので
極値は最終的に周期的になる。空状態の極値は `overline(3132)` と `overline(1323)`。
各選択は `2` を続けて延長できるので、貪欲な極値選択に行き止まりはない。

どの状態でも、最初の数字が3の部分と2の部分の間に、同じ隙間

\[
(x,y),\qquad x=\frac1{3+a},\quad y=\frac1{2+b}
\]

がある。両端は実現される。尾部凸包の左端を `m` とすると、
`m=a`（状態0,13）、`m=c`（状態1）。
隙間の左端から左へ向かう橋は凸包の左端を越えられないので、長さは高々 `x−m`。
途中に別の大きな隙間があれば橋はさらに短い。

\[
\phi_U(z)=\frac{A z+B}{C z+D},\qquad r=C/D
\]

を施すと、向きにかかわらず、この橋と隙間の比は高々

\[
R_m(r)=\frac{x-m}{y-x}\frac{1+ry}{1+rm}.
\]

`y>m` より `R_m` は `r` に関して増加する。
空語では `r=0`。非空語の最後の数字が `j` なら `r=1/(j+r_prev)`。
したがって、終状態による一様上界とその代入値は

| 終状態 | `r` の上界 | `R_m(r)` の上界 |
|---|---:|---:|
| 0 | `1/2` | `(19−5√10)/4 = 0.7971529…` |
| 1 | `1` | `(5−√10)/6 = 0.3062870…` |
| 13 | `1/3` | `√10−19/8 = 0.7872776…` |

状態0で最後の数字は2または3、状態13で最後の数字は3である。
3つの上界の最大値が主張の定数。有限サンプルではなく、単調性により全語に成立する。□

**意味。** Hall の「各隙間の両隣が隙間より長い」という単純な方法や、
全円柱二つに厚みの積条件を適用する方法では足りない。
Schecker の補助区間による左右の組合せ、または Freiman の端点短縮・選択履歴のように、
和における複数の表示の重なりを使う必要がある。
この命題だけから、特定の Schecker 型構成が不可能だとは結論しない。

## 3. Schecker の極限論法を候補の有限集合へ拡張する

一つの語対ではなく、有限個の語対

\[
\mathcal B=\{(U_i,V_i):1\le i\le m\}
\]

を一つの節点で保持する。その真の和と外側評価を

\[
E(\mathcal B)=\bigcup_i(K_F(U_i)+K_F(V_i)),\qquad
O(\mathcal B)=\bigcup_i\operatorname{conv}(K_F(U_i)+K_F(V_i))
\]

とする。`O` は合併そのものであって、合併の凸包ではない。

**候補集合による後続被覆補題（十分条件）。** 節点に担当閉区間 `J` を持たせ、
次を全許容節点について示せたとする。

1. `J ⊂ O(B)`。
2. 有限個の後続節点 `(B_j,J_j)` が存在し、`J ⊂ ⋃_j J_j`。
3. 各 `B_j` の各語対は、親 `B` のいずれかの語対の合法な両側延長である。
4. ある共通の `0<λ<1` に対して、各後続の最大和凸包幅が親の最大和凸包幅の `λ` 倍以下。

このとき `J ⊂ E(B)`。

**証明。** `t∈J` を固定し、同じ `t` を担当する後続節点を選び続ける。
第1条件より各世代で `t` を含む和凸包がある。その凸包の元になる真の和から一点 `s_n`
を取ると、第4条件より `|s_n−t|≤λ^n δ_0`。
第3条件より `s_n∈E(B_0)`。初期の `E(B_0)` はコンパクトなので `t∈E(B_0)`。□

各世代で選ぶ語対自体が一本の入れ子列になる必要はない。
候補の集合全体は初期の真の和の内部に残るので、コンパクト性で足りる。
これにより、複数の表示のうちどれを無限に使うかを早期に確定せずに済む。
Schecker の単一語対の構成は `m=1` の特別な場合である。

第4条件は十分条件として強めに置いた。
固定ステップ数ごとの一様縮小や、全経路での幅の一様収束でもよい。
有限深さだけの幅減少は、全深さについての条件の証明にはならない。

## 5. Lagrange スペクトルへの帰着

共有議論の次の包含は、内点の証明とは切り離せる。

\[
(3+K_F+K_F)\cap(191/45,c_F)\subset L\setminus[c_F,\infty).
\]

左右の語の長い有限部分を中央の3のまわりに置き、区切りの2を挟んで繰り返す。
中央以外の3には少なくとも片側に2以上が隣接する。
すべての123連分数の尾部は `[1/4,4/5]` 内なので、その位置の局所値は高々
`3+4/5+4/9=191/45`。1,2の位置は高々 `18/5`。
中央の局所値は目標に収束し、目標はこれらの上界を超えるので limsup が目標になる。

従って第4節の `J` を真に充填できれば
`[4.29288,4.292906] ⊂ L` が従い、Hall の半直線より下の内点になる。
これは十分大きな未解決の結論である。
[Erazo–Jeffreys–Moreira の2025年版論文の序論](https://arxiv.org/html/2405.20581v2)
でも、Hall の半直線以外の区間と Berstein の予想は未解決とされている。

補足として、**全体で** `131` を避ける両側無限列の局所 Perron 値の最大値は

\[
3+b+d=\frac{4\sqrt{10}}3=4.216370213557839\ldots.
\]

3の両隣がともに1にはならず、大きい側の尾部は高々 `b`、他方は高々 `d`。
この組は実現でき、1,2の局所値より大きいので最大値となる。
ただし中央に例外的な `131` を挿入する上の構成には、この改善値をそのまま使わない。
中央から有限距離の尾部は例外を含み得るため、ここでは安全な `191/45` の評価を保つ。
