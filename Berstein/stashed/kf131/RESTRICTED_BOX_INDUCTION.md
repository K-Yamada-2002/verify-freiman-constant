## 隙間の外包絡を箱ごとに計算する

以前は反例を発見した広い箱で求めた「移動する隙間の外包絡」を、
それと交わる小箱でも同じ幅で除いていた。これは探索を過剰に制限する。

小箱へ制限すると、下側の端点に対する下界は上がり、上側の端点の上界は下がる。
従って外包絡は狭くできる。外包絡全体が空とは主張せず、
残した区間の充填も証明したことにはしない。

## 未解決型の同値な統合

型の命題を `P(B,I):「全てのパラメータ b∈B で I が和に含まれる」` と書く。
次の二つは単なる命題の同値変形である。

- 同じ箱の二つの区間が重なる、または接するとき、
  `P(B,I1) ∧ P(B,I2) ⇔ P(B,I1∪I2)`。
- 同じ区間で比率の箱が二分割の兄弟であるとき、
  `P(B1,I) ∧ P(B2,I) ⇔ P(B1∪B2,I)`。
  左右の形状の箱が同じなので、後者の合併は再び一つの積の箱になる。

`coalesce_open_types.py` はこの二つだけを使う。
根や検証済みの条件付き局所規則の親を広げず、開いた子型だけをまとめる。
統合後も子は未解決であり、参照を書き換えた親の規則は全て再検証する。
スカラー区間の隙間や非隣接の比率箱を埋める操作はしない。
最初の帰納規則では、子2型を比率の兄弟箱として1型にまとめられる。

## 数字2による厳密な中央帰還

別の試行として、実在する到達円柱対の両側に `2` を8個付け、
両側の形状が `22222222` となる型を作った。
`periodic_return_seed_20260924.json` に初期円柱対を保存した。
`alpha=sqrt(2)-1`, `phi_2(x)=1/(2+x)` とすると、厳密に

```
D_r(phi_2(x)) = -alpha^2 D_{1/(2+r)}(x)
```

が成り立つ。したがって両側に2を付ければ `h` と相対偶奇は不変で、
正規化スカラー区間は `-alpha^2` 倍される。
8個の2で定まる形状箱は、この形状写像で自分の中へ入る。
よって対称区間 `J=[-a,a]` に対し、`[-alpha^2*a,alpha^2*a]` の自己帰還を
厳密に検証できる。ただし、これだけでは `J` の両端側を覆えない。

探索コードには、その帰還を妨げる二つの余分な制約があった。

1. 到着する比率区間と端点で接するだけの隣接セルまで、必須の子としていた。
   正の幅の到着区間ではこれを除き、残ったセルによる閉区間被覆を厳密検証する。
2. 既存型が逆像全体を覆うときだけ再利用し、小さい区間を使う部分的な帰還候補を出していなかった。
   `--library-fragments` により、必要な全パラメータ箱で共通に使える部分区間も候補にする。

この修正で二つの中央帰還候補を実際に生成・再利用できた。
一方、試した4桁までの後続では外側まで含む閉包は得られなかった。
選択された被覆はさらに別の大きい区間の義務を要求し、その全体を覆えなかった。
`periodic_return_continued_20260924/history.json` に記録した。
中央の自己帰還だけを完成した帰納と誤認しないことをテストしている。

## 片側2の往復：比率の帰還とスカラー区間の帰還を分離

`periodic_cycle_diagnostic.py` は、上の2型について比率の丸めを外した場合を
既存の厳密な遷移・スカラー像の計算で検査する。証明用スキーマの変更はしていない。
結果は `periodic_exact_cycle_diagnostic_20260924.json` に保存した。

`c=alpha^2=3-2*sqrt(2)` と置く。`c<h<1` では、左だけに2を付けて左右を
交換すると、比率と偶奇は `(h,p) -> (c/h,-p)` となる。したがって

```
H=[h_-,h_+],  K=[c/h_+,c/h_-]
```

を用いれば、比率の箱は `H -> K -> H` と厳密に往復する。
両側の形状箱も8個の2で定まる同じ箱へ戻ることを検証した。

しかし、対称スカラー区間 `J_0=[-a,a]`, `J_1=[-b,b]` に対する
この2本の辺の一様被覆核は、それぞれ

```
[-h_-*b,h_-*b],  [-(c/h_+)*a,(c/h_+)*a]
```

である。この2本だけで全区間を覆うには `a <= h_-*b` と
`b <= (c/h_+)*a` が必要だが、掛け合わせると
`1 <= c*h_-/h_+ < c < 1` となり矛盾する。
両側に2を付ける中央自己帰還を追加しても、各区間の端点には届かない。
これはこの対称2型・指定した帰還だけについての不可能性であり、
他の分岐を含む有限帰納や内点の存在を否定するものではない。

現在の候補では `a=0.05`, `b=193244909/1024000000` で、
子型の必要区間は約 `[-0.188716,0.188716]`、帰還核は約
`[-0.0323765,0.0323765]` である。従って比率箱の厳密化だけを実装しても
不足は解消しない。そこで外側には、数字1または3を含む別の分岐を割り当てる。

なお比率だけでも、全ての端点を有理数に固定するとこの2箱の厳密な往復は
実現できない。`f(h)=c/h` に対し `f(H) subset K`, `f(K) subset H` なら
`f(f(H))=H` より両包含は等号となるが、有理数端点の `H` の像は無理数端点を持つ。
これは将来この往復を利用する際の箱表現の制約として残る。

再現:

```sh
python3 periodic_cycle_diagnostic.py periodic_return_continued_20260924/current.json \
  --output periodic_exact_cycle_diagnostic_20260924.json
python3 -m unittest test_periodic_return
```

## 担当区間の分割による続行

`split_scalar_obligations.py` は、開いた非根の義務だけをスカラー方向に分割する。

`B` 上で `I` が充填される命題は、同じ `B` 上で各 `I_j` が充填される命題の
連言と同値である。親の到着先を全ての必要な部分へ付け替え、
`B x I` の積被覆を独立に再検証する。分割を新しい被覆規則とは数えない。
初期区間も狭めず、実在の種の物理区間が完全に同じであることを検査する。
