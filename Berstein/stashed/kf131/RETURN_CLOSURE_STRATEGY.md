# 帰還を閉じるための構造検査（2026-09-24）

内点存在の証明は未完成。このノートは、局所規則の数を増やすことと、
有限の帰納が閉じることを区別するための検査と試行を記録する。

翌日の箱と帰還語を広げた探索は [RETURN_DOMAIN_EXPLORATION.md](RETURN_DOMAIN_EXPLORATION.md) を参照。

## 現在の51型だけでは短い帰還が閉じない

対象は `periodic_outer_all_five_coalesced_20260924.json`。
`audit_return_barrier.py` は、左右に付ける合法な語の総長が4以下のものを全て列挙し、
到着形状箱が既存の型の形状箱に含まれ得るかを厳密に検査する。
交換と偶奇も含めた必要条件の辺は1007本となった。
比率やスカラー区間の条件をまだ課していないので、実際の辺を落としてはいない。
ただし、現在の検証器と同じく、各到着先の形状箱が到着形状全体を含む形式を対象とする。

型の左右の末尾文字列について、先頭に連続する2の個数を足したものを `P` とする。
根は `P=16` で最大である。根以外から出る全ての必要条件の辺で、厳密に `P` が減る。
従って根以外の型はこの有限集合内で循環できず、根へも戻れない。
閉じた有限の規則系に残れるのは根だけになる。

根だけへ戻る形状上の候補に比率条件を課すと、残る語は
`('2','2')` と `('22','22')` だけである。
`c=(sqrt(2)-1)^2`、根の区間を `J` とすると、これらの最大の被覆核は
それぞれ `-c J` と `c^2 J` である。根の `J` は約 `[-0.188716,-0.187716]` なので、
どちらも `J` を覆わず、合わせても覆わない。

したがって、**現在の51型・総長4以下の語・現在の一様被覆検証形式だけでは閉包を作れない**。
新しい型、より長い語、別のパラメータ箱、別の検証形式を否定するものではなく、
和集合に内点がないという結論でもない。

再現:

```sh
python3 audit_return_barrier.py periodic_outer_all_five_coalesced_20260924.json \
  --output periodic_return_barrier_verified_20260924.json
python3 -m unittest test_return_barrier
```

非根にも自己帰還がある入力では、この単調量から不可能性を結論しないこともテストした。

## 同じ物理区間を、短い形状の記憶で試す

8桁の形状末尾を持つ型では、最初に付けた2の列を落とすまで、
短い語による循環が作れない。そこで別の枝として、根の形状末尾を
`22222222` から `2222` に変えた `periodic_memory4_seed_20260924.json` を作った。
実在する初期円柱対、比率箱、スカラー区間は同じである。

旧形状箱は新形状箱に含まれる。したがって、新しい一様充填命題は旧命題より強く、
古い規則をそのまま証明として流用していない。初期包絡と実在の種を再検査し、
物理区間が完全に同じであることを厳密に確認した。
到着型には4桁の形状末尾と比率の16分割を使う。

## 既存の型へ戻る候補を優先する

`repair_gap_intervals.py` と `continue_gap_closure.py` に `--prefer-reuse` を追加した。
現在の被覆点から正に進める候補のうち、全ての到着先が既存ライブラリの型であるものを
先に選ぶ。短い帰還核が、新しい型を要求する大きい核に毎回押しのけられるのを避ける。
その後も正の進行を要求し、区間の最後まで覆うことと、全ての子への依存を従来どおり検証する。
既存の型へ戻る辺を選んだこと自体を、帰納の閉包とは数えない。

## 既存の型だけによる最大不動点を直接探す

`close_scalar_library.py` は、新しい型を追加せず、指定した語長までの合法な帰還候補を
全て調べる。各到着比率区間を端点で分割し、全ての比率の小区間で使えるスカラー区間の
共通部分を求める。比率とスカラーの射影がそれぞれ覆われるだけでは受理しない。

最初は全型を候補に残し、その集合だけを到着先に使って全区間を覆えない型を除く。
除くたびに、残った長方形から被覆候補を作り直す。これにより、不要な到着先への依存や、
最初に選んだ1つの規則だけが原因で、別の閉じた規則系を見落とすことを避ける。
有限回で安定し、残った型の規則を独立の `ScalarVerifier.local()` で検証する。
実在の種を持つ根まで残った場合に限り、`ScalarVerifier.closed()` による最終検証を行う。

この検査でも、元の51型（総長4まで、比率まで通る幾何候補67個）の最大不動点は空だった。
`periodic_memory8_library_closure_20260924.closure.json` に保存した。
4桁の枝の最初の31型についても、幾何候補27個から始めて
`31 -> 11 -> 4 -> 1 -> 0` と候補が消える。
`periodic_memory4_library_closure_20260924.closure.json` に保存した。
初回に除かれたのは未解決型だけで、検証済み局所規則を持つ11型は初回を全て通過した。

これらは固定した型集合と検証形式に対する結果であり、より大きなライブラリ、
細分化した別の区間型、より長い語による閉包を否定していない。

## 4桁の枝の保存状態と、長い帰還の結果

4つの未被覆親区間を、それぞれ被覆核の端点に合わせて3分割した。
12区間すべてに条件付き局所規則を作れたが、到着先に未解決の義務が残る。
保存状態は **`periodic_memory4_partition_current_20260924.json`**。
58型・23局所規則・35未解決型で、元の物理的候補区間は維持している。
`periodic_memory4_partition_verification_20260924.json` で全初期包絡、全局所規則、
実在の種と旧種との一致を厳密に検査した。閉包検証は未解決型45で拒否する。

さらに、到着先の左右の4桁の形状語をそのまま末尾に持ち、その前に各々0〜1桁を
付ける総長8〜10の帰還語も加えた。これは10桁までの全列挙ではない。
58型上の幾何候補は167個になり、根以外にも18型の強連結成分が現れた。
しかし、スカラー被覆を課した最大不動点の削除過程は
`58 -> 23 -> 7 -> 3 -> 1 -> 0` となり、閉じた成分は残らなかった。
結果は `periodic_memory4_block_closure_20260924.closure.json` と
`periodic_memory4_return_components_20260924.json` に保存した。

## 区間を動かしても閉じないことを示す長さの証明書

単に現在の区間が悪いだけなのかを切り分けるため、区間長の必要条件を作った。
同じ形状・偶奇・比率箱を持つ型をまとめると24種類になる。
それぞれの箱について、仮に一様充填を証明する有限区間和を `S_i`、
そのルベーグ測度を `m_i` とする。同じ箱の区間は任意に動かしたり、
細分化したりしてよい。各箱内で1つの有理パラメータ点を選ぶ。

帰還語 `(u,v)` の、その点でのスカラー写像の傾きの絶対値は、交換なしなら
`1/f_u(r)^2`、交換ありなら `h/f_v(s)^2` である。
合法な帰還候補について、その点の到着比率を含む全到着箱への傾きを加算して
非負行列 `A` を作る。重なりは重複して数えるため、被覆から得られる必要条件は

\[
  m_i\leq\sum_j A_{ij}m_j.
\]

`audit_return_widths.py` は正の有理ベクトル `w` を発見し、厳密な数体演算で

\[
  Aw < \frac58 w
\]

を確認した。実際の最大比は約 `0.624766247697816819`。
数値計算は重みの候補発見だけに使い、全不等式は厳密に検査する。
もし `m` が非零なら、`m_i/w_i` が最大となる `i` で上の二つの不等式が矛盾する。
従って、この固定した帰還形式では全て `m_i=0` でなければならない。

総長4以下の全語と上記の長い帰還語では81幾何候補、
総長6以下の全語へ広げると88幾何候補となるが、どちらにもこの証明書がある。
これらは24種類に統合した後の数であり、58型上の167候補とは数え方が異なる。
各語の傾き、加算行列、有理パラメータ、重み、厳密な正の余裕、入力のハッシュを保存した。
保存された各係数を語から再計算し、行列への加算と不等式も再検査した。

```sh
python3 audit_return_widths.py periodic_memory4_partition_current_20260924.json \
  --length 6 --output periodic_memory4_width_barrier_length6_20260924.json
```

証明書は `periodic_memory4_width_barrier_20260924.json` と
`periodic_memory4_width_barrier_length6_20260924.json`、
係数と不等式の再検査結果は `periodic_memory4_width_replay_20260924.json`。

**適用範囲は、保存されたパラメータ箱・列挙した帰還語・現在の一様被覆形式に限る。**
各帰還で到着形状全体の包含と到着比率全体の被覆を要求する形式であり、
親のパラメータ箱の一部だけに適用する帰還は含まない。
新しいパラメータ箱、その細分化、さらに別の帰還語、パラメータに依存して動く区間は
排除していない。これは `K_F+K_F` の内点不存在の証明ではない。

今回分かったのは、同じ有限ライブラリでスカラー区間だけを直し続ける方針には
限界があるということ。帰納を閉じる次の探索では、未解決区間をさらに分割する前に、
帰還先のパラメータ箱や帰還語を追加し、この長さの障害を越える必要がある。
長さの障害が消えること自体も、区間被覆の十分条件ではない。
