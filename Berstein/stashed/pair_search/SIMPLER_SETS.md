# Gauss–Cantor集合の定義を簡単にする検討

現在の11命題には、禁止語が `131` のみの **K_F 全体の自己和 K_F+K_F は含まれていない**。従来の探索は安全な区間被覆を優先し、禁止語の個数や長さを目的関数にしていなかった。以下は既存候補を変更せず、簡略化の選択肢を別に調べた結果。

## 禁止語を削除する安全な簡略化

各禁止語とその逆順をまとめて削除する候補を試し、半径4の背景窓と全交差組の中央近傍を有理数で再評価した。削除は集合を広げるため、元の因子を維持すれば、既存の全域・局所被覆や点近似の保証をそのまま引き継ぐ。局所的な貪欲探索であり、最小個数は主張しない。

|元の命題|禁止語数の変化|
|---:|---:|
|2|13 → 11|
|3|17 → 15|
|6|5 → 3|
|9|11 → 10|

特に第6命題では、S を数字123・禁止語 `{131,2313,3132}` の集合とすれば、

`S[11,12,133] + S[11,12,2] ⊇ [1.178461,1.219534]`

という3禁止語の命題に置き換えることができる。包含は未証明だが、旧候補からの集合包含により数値的保証は引き継ぎ、Perron支配条件も新しい大きな集合について確認した。

また第11命題の基本集合 J の4禁止語は、`a131b (a,b∈{2,3})` という1つのパターンで表せる。これは同じ集合の簡潔な表記であり、新たな数値仮定は不要。

## K_F+K_F そのものの候補

`K_F+K_F ⊇ [1.27,1.36]` は、全区間で距離 `10^-8` 以下の整数被覆と、101点で誤差 `<10^-30` の有理数検証を通過した。包含の証明ではなく、既存11命題の全域 `10^-9` と同じ精度まで検証したわけでもない。

中央以外の値を `191/45` 以下に抑える [既存の帰着](../kf131/README.md#5-lagrange-スペクトルへの帰着) を使うと、この包含を証明できれば `[4.27,4.36] ⊂ L` が従う。全域を1組で扱えるという意味ではない。

実際に **`[1.3720,1.3727] ∩ (K_F+K_F) = ∅`** を有理数のみの円柱分割で確認した。全9個の最初の数字の組から始めて75節点を処理し、51個の葉を全てこの閉区間と分離した。従って後半全域を K_F+K_F だけに置き換えることはできない。

## 単純化できなかった例

第7命題を `K_F[11]+K_F[11] ⊇ [1.219532,1.235001]` に替える案は棄却した。Perron支配条件と101点の高精度近似は通ったが、全区間の `10^-9` 検査で16個の穴を検出。例えば和の値が約 `1.2339224892049072` から `1.2339233814813937` の閉区間は、独立した有理数計算でも非包含を確認した。正確な端点は [記録](kf_cylinder_check.json)。単に禁止語の少ない小集合へ縮めると、必要な区間が失われることがある。
