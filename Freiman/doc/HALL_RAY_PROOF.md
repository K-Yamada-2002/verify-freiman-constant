# Schecker 型の反復による Freiman 半直線の証明

2026-09-29。今回構成した閉じた後続被覆から、

\[
\boxed{[c_F,\infty)\subset M\cap L,\qquad
c_F=\frac{2221564096+283748\sqrt{462}}{491993569}}
\]

を得た。固定した証明書は `hall_ray_certificate.json`、その再検証は
`verify_hall_ray.py`、検証結果は `hall_ray_verified.json`。
これは解析的な反復・接合の証明と、厳密算術による計算機検証を組み合わせた証明であり、
Lean による形式証明ではない。

Schecker の既存の半直線包含や Hall の定理を上側の接続に用いる必要もなくなった。
Freiman 原論文由来の初期区間表、Lean の資料、`stashed` のコードは用いていない。
**ここで証明したのは半直線包含であり、下端をこれ以上下げられないという最大性は対象外。**

## 1. 維持する許容性と閉包版 Lem2

左右の外向き固定語を \(a,b\in\{1,2,3,4\}^*\) とする。
追加数字は1,2,3であり、固定語を含む左右それぞれの無限語全体で31313を禁止する。
許される二つの連分数の和の凸包を \(I(a,b)=[L(a,b),U(a,b)]\)、幅を \(W(a,b)\) と置く。

\[
J_{p,q}(a,b)=[L(a,b)+pW(a,b),\ L(a,b)+qW(a,b)]
\]

のうち、反復可能なものを許容帯とする。一般族の状態は、左右の禁止語 DFA 状態、
長さの偶奇、末尾2桁、分母比 \(r,s\) の箱、下端での微分比

\[
S=\frac{|F_b'(\xi_b)|}{|F_a'(\xi_a)|}
=(q_a/q_b)^2\frac{(1+r\xi_a)^2}{(1+s\xi_b)^2}
\]

の箱、および帯の型からなる。基本型は \((0,1)\) と
\((j/32,(j+2)/32)\), \(0\le j\le30\)。

**Lem2。** 検証済み一般族の各状態、ならびに端点の特別な型 E、R0、R1 について、
親の対象区間は有限個の真の3後続の対象区間で被覆される。
全ての後続は同じ一般族または特別な型のいずれかに属する。
一般族への遷移が複数のパラメータ箱にまたがる場合、その全てについて帰属が成立する。

一般族の詳細は [INVARIANT_SEARCH.md](INVARIANT_SEARCH.md)、
特別な型の祖先・反復回数を含む条件と全186後続は
[ENDPOINT_LEMMA.md](ENDPOINT_LEMMA.md)、[ENDPOINT_MENUS.md](ENDPOINT_MENUS.md) にある。
今回の証明で使う一般族は次の二つ。

| 一般族 | 固定して再検証した状態数 | 過去側の分母比 |
|---|---:|---|
| `graph_m2` | 2,894,882 | [0,1] |
| `graph_wide` | 3,464,816 | [1/4,4/5] |

各表は、それぞれ単独で反復が閉じている。複数の表の帯を結合して初期被覆を作っても、
各帯の表現にはその表自身の閉包補題が使える。

**反復から表現可能性への証明。** 対象点を含む後続を選び続ける。
\(S\) の正の上下界と、微分の大きさが \(q^{-2}\) に一様に比較できることから、
両側の語の長さが無限に伸びる。後続の全円筒は親の全円筒に含まれ、その幅は0に収束する。
したがって対象点は、禁止条件を保つ二つの無限連分数の和になる。
補助帯そのものの親への包含は必要なく、対象点の帰属と全円筒の入れ子性を使う。

## 2. 非中心値を同時に支配する有限初期被覆

中心数字 \(c\in\{4,5\}\) を入れた両側列について、各初期根の全ての許された延長に対し

\[
\sup_{i\ne0}\lambda_i\le\Theta(a,b;c)
\]

を計算する。有限中心部を全位置で調べ、その外側7桁までを列挙する。
さらに遠い全位置は、31313を避ける両側1,2,3列との連分数の差を使って

\[
\lambda_i\le M_B+\frac1{441},\qquad
M_B=\frac{4\sqrt{462}}{19}<c_F
\]

と囲む。有限の位置だけを調べて残りを省略してはいない。
厳密な実装と証明の説明は `spectral_bounds.py` と [RESULTS.md](RESULTS.md) の第1節にある。

充填済みの帯に対し、Markov スペクトルに入ることを主張するのは必ず

\[
D(c,a,b;p,q)=
\left[\max\{c+L+pW,\Theta(a,b;c)\},\ c+L+qW\right]
\]

の部分である。任意の \(t\in D\) に対し中心値が \(t\) の延長が得られ、
非中心値は全て \(\Theta\le t\) なので、\(m=t\) となる。

端点の根 \((A,B)=(32113,4322)\)、中心数字4については、特別な型の補題から

\[
E_0=[c_F,c_F+W(A,B)/8]\subset M,
\qquad\Theta(A,B;4)<c_F
\]

が得られている。この区間に**93本の帯**を順に接続することで

\[
E_0\cup\bigcup_{j=1}^{93}D_j
\supset[c_F,H_*],\qquad H_*=6.524726426110279\ldots>13/2
\]

を得る。最後の帯は中心数字5、\(a=13,b=121\)、\((p,q)=(1/32,15/16)\) である。
93本で使う非中心上界は91組の根について独立に再計算する。
固定語の最大長は左右それぞれ6桁。

全ての端点比較、\(\Theta\) による切り詰め、前の右端との重なりは
\(\mathbb Q(\sqrt{462})\) で検証する。小数の近さを接触とみなす判定は使わない。
初期語と帯の全リストは [HALL_RAY_INITIAL_COVER.md](HALL_RAY_INITIAL_COVER.md) にある。

## 3. 43本の帯の整数移動で無限遠まで覆う

中心数字をまだ入れない、連分数の和の区間として、43本の充填済み帯 \(T_j\) により

\[
\boxed{[1/2,3/2]\subset\bigcup_{j=1}^{43}T_j}
\]

を検証した。この部分の固定語は全て1,2,3,4からなり、左右それぞれ3桁以下である。
追加数字は1,2,3で、同じ31313禁止を保つ。

任意の整数 \(n\ge6\) を中心数字に置く。中心以外の全数字は4以下なので、
全ての非中心位置で、連分数の両尾が1未満であることから

\[
\lambda_i<4+1+1=6\le n<t\qquad(i\ne0)
\]

となる。よって帯の表現可能性から

\[
[n+1/2,n+3/2]\subset M\qquad(n\ge6)
\]

が従う。隣り合う整数の区間は端点で接し、

\[
\bigcup_{n\ge6}[n+1/2,n+3/2]=[13/2,\infty).
\]

第2節の有限被覆と合わせて、\([c_F,\infty)\subset M\) が証明された。
この整数移動は中心値だけを動かす。一般に低い中心数字で非中心値の支配が保たれるとは仮定せず、
ここでは \(n\ge6\) という条件を明示して用いている。

## 4. 同じ構成から Lagrange 半直線も得る

上で各 \(t\ge c_F\) に対して構成した両側列 \(C\) は、有限中心部を除けば
数字1,2,3からなり、左右の尾で31313を回避し、\(m(C)=\lambda_0(C)=t\) を満たす。

窓 \(C[-m,m]\) を、長さが無限に増える2の列を挟んで \(m\to\infty\) とともに並べる。
固定した半径 \(R\) に対し、十分後ろの半径 \(R\) の窓は、元の \(C\) の窓と一致するか、
全ての数字が1,2,3で31313を含まない。接合部をまたぐ31313は、間に2があるので生じない。
後者の有限窓は2で延長すれば両側の禁止語回避列になる。

連分数の一様な連続性から、十分後ろの局所値は

\[
\max\{t,M_B\}+\frac{2}{F_{R+1}^2}
=t+\frac{2}{F_{R+1}^2}
\]

以下である。\(R\to\infty\) とすると上極限は \(t\) 以下。
一方、各コピーの中心値は \(t\) に収束するので、上極限は \(t\) 以上。
したがってこの列の Lagrange 値は \(t\) であり、\([c_F,\infty)\subset L\) も従う。

## 5. 検証と探索を分ける

固定リストの通常の再検証：

```bash
python3 -B Freiman/lemma2_search/src/verify_hall_ray.py
```

この実行では一般族の保存済み全行検証の入力・結果・ソースのハッシュを照合し、
端点の186後続を再検証し、93本と43本の全ての帯の型・箱への帰属、端点、接続を再計算する。
非中心値上界も91組と端点の根について再計算する。

一般族の入力生成と全行検証も含めた実行：

```bash
python3 -B Freiman/lemma2_search/src/verify_hall_ray.py --full
```

失敗する行を削って成功扱いにする処理はない。下端の入口、有限被覆の最後の帯、
整数移動用被覆の最後の帯をそれぞれ削った負の対照検査は、被覆失敗を検出する。

探索を再実行する場合は `build_hall_certificate.py` を使う。
短い語の候補を浮動小数で絞り、候補帯への帰属と採用する全ての接続は厳密算術で確認する。
初期候補で残った隙間の右側は、合計長12、片側長6までの語を追加探索した。
`--regenerate-template` を付けると、整数移動用の短い語の候補も再列挙する。
探索による成功フラグとは別に、上記の固定検証が成功することを証明書の条件とする。
