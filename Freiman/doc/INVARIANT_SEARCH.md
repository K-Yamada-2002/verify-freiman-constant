## 区間と状態

31313禁止は左右の固定語全体と全ての延長で保持する。追加数字は1,2,3。
左右の固定語を \(a,b\)、従来の全凸包を
\(J_F(a,b)=[L(a,b),U(a,b)]\)、その幅を \(W(a,b)\) とする。
今回の補助区間は

\[
J_{p,q}(a,b)=[L(a,b)+pW(a,b),\ L(a,b)+qW(a,b)]
\]

で、型は \((p,q)=(0,1)\) と
\((p,q)=(j/32,(j+2)/32)\), \(0\le j\le30\) の32種類。
これは「どの部分区間を次に覆う必要があるか」を親の状態に加えたものである。
定義だけでその部分が表現できるとは主張しない。閉じた後続被覆から表現可能性を導く。

離散状態は左右の禁止語オートマトン状態、長さの偶奇、末尾2桁、区間型。
連続パラメータは

\[
r=q_{a^-}/q_a,\qquad s=q_{b^-}/q_b,\qquad
S=\frac{|F_b'(\xi_b)|}{|F_a'(\xi_a)|},
\]

とする。\(\xi_a\) は \(F_a\) の最小値を達成する尾なので、
長さが偶数なら状態付き尾集合の最小端点、奇数なら最大端点である。
\(\xi_b\) も同様。

\[
S=(q_a/q_b)^2\frac{(1+r\xi_a)^2}{(1+s\xi_b)^2}.
\]

比の箱は \([(51/50)^i,(51/50)^{i+1}]\), \(-117\le i\le116\)。
許容性の定義で最終的に残すのは、閉包検証を通った箱と区間型だけである。

### 反復で保持できる、過去側の範囲

\[
Q_0=[1/4,4/5],\qquad \frac1{d+Q_0}\subset Q_0\quad(d=1,2,3).
\]

したがって既知の末尾 \(v\) の前の分母比が \(Q_0\) にある条件は、
追加数字1,2,3のもとで保存できる。
\(r\) の箱には \([0;\operatorname{rev}(v)+t]\), \(t\in Q_0\) の範囲を使う。
禁止語状態が末尾2桁より長い場合は、その長い末尾を使う。
`--tight` がこの条件であり、以前の過去側 \([0,1]\) の箱と区別する。

初期語 \(32113,4322\) はこの条件を満たす。
根の正確な分母比が箱に入ることと、各追加語による箱の像が子の箱に入ることは、
`certified_kernel_input.py` が有理数で検証する。

## 今回の Lem2 の形

有限表 \(\mathcal A\) は上の状態・箱・区間型の集合とする。
各状態において、選ぶ後続は

\[
\bigl(au_\nu,bw_\nu,p_\nu,q_\nu\bigr),\qquad
|u_\nu|+|w_\nu|>0,
\]

で、追加語に使う数字は1,2,3だけである。
候補は短い追加語、および極値尾の6桁周期に沿う追加語とそこから分岐する追加語。
現在の候補表では追加長の和は12以下。

**閉包版 Lem2。** 許容状態 \(\mathcal A\) の各行の箱全体で、

\[
J_{p,q}(a,b)\subset\bigcup_\nu J_{p_\nu,q_\nu}(au_\nu,bw_\nu)
\]

が成り立ち、全ての後続のパラメータ像が同じ \(\mathcal A\) の対応する箱で覆われるなら、
各許容区間の全点は31313を回避する二つの無限延長の和である。

証明は Schecker 型の反復そのもの。
目標点を含む後続を選び、同じ許容族の内部で繰り返す。
\(S\) は正の上下界を持ち、\(|F_a'(\xi_a)|\) は \(q_a^{-2}\) と一様に比較できるので、
片側だけが無限に伸びることはない。
両側の全円筒の和の凸包は入れ子で、幅は0へ収束する。
したがって目標点は極限の二つの連分数の和に一致する。
補助部分区間自体が親に包含される必要はない。

## 閉包を作る削除操作

最初に有限個の候補状態全体を \(\mathcal A_0\) とする。
\(\mathcal A_n\) の行のうち、その集合に戻る後続だけでは親を覆えないものを除き、
\(\mathcal A_{n+1}\) とする。候補の子の像が複数の箱にまたがる場合は、
**その全ての箱が残っていること**を要求する。

\[
\mathcal A_0\supset\mathcal A_1\supset\cdots\supset\mathcal A_N=\mathcal A_{N+1}.
\]

有限集合なので停止する。非空の固定点が得られれば、その集合には未処理の前線がない。
各残存状態に局所被覆があり、全ての選んだ後続が同じ集合へ戻る。
従って上述の Lem2 を適用できる。
途中の生存状態数や、まだ削除が続いている集合を証明とは扱わない。

## 厳密判定と証明書

`kernel_search.cpp` は数値的な候補探索だけに使う。
一方、`graph_kernel.cpp` は分母 \(2^{48}\) の有理区間と128ビット整数の中間積によって判定する。
各演算で外側へ丸め、重なりの判定に許容誤差を足さない。
入力の二次体の量は、有理数で挟んだ平方根から外向きに丸める。
子の分母比の像の包含も入力作成時に厳密に検査する。

端点差の片側項は

\[
\frac{(1+r\xi)^2(x-y)}{(1+rx)(1+ry)}.
\]

二つの正の一次分数の範囲を端点から囲んで、その積を評価する。
部分区間の端点は二つの全端点の有理係数の凸結合なので、
差を上式の正係数の和に分解して評価できる。
同一の尾は厳密に識別して相殺する。

候補区間どうしは、箱全体で重なることを示す**両方向**の端点不等式が通った場合だけ接続する。
固定した連結成分が親の両端を覆えば、その箱全体の被覆になる。
区間を並べる順序に使う浮動小数は探索上の補助であり、採用する全ての辺と端点条件は
有理区間演算で再判定する。

`graph_kernel_verify input.dat replay.json saved.alive.bin` は、保存された集合を固定し、
全ての生存行を一度ずつ再検査する。失敗した行を削って成功扱いにはしない。
反例があれば非ゼロ終了する。

`verify_dyadic.py` は整数の積・商の外向き丸めを Python の `Fraction` で2000件検証する。
`verify_graph_controls.py` は既知の閉じた被覆族が残ること、
中間に穴を作った族と片端を失った族が除かれることを検証する。

### 再現手順

リポジトリの根で次を実行する。Python 標準ライブラリと C++17 コンパイラを使う。

```bash
python3 -B Freiman/lemma2_search/src/verify_invariant_certificate.py graph_m2
python3 -B Freiman/lemma2_search/src/verify_invariant_certificate.py graph_tight
python3 -B Freiman/lemma2_search/src/verify_invariant_certificate.py graph_wide
```

入力を厳密算術から作り直して既存の `.dat` とバイト単位で照合し、
検証器をコンパイルし、保存した `.alive.bin` の全生存行を固定して検証する。
最後に根の後続リストを別の代数的評価で検査し、入力・結果のハッシュを
`*_verification_manifest.json` に記録する。
失敗した状態を削って成功扱いする手順ではない。
Lean による形式証明ではなく、解析的な反復論証と厳密算術による有限検証である。

負の対照検査では、真の穴がある `3131|3131`、\(S=1\) の F 型を保存集合に1行だけ
不正に追加した。固定集合の再検証はちょうどその1行を拒否した。
`closed_family_negative_control.json` に記録した。

\((3697-172\sqrt{462})^n\), \(1\le n\le12\) で正値を保つことを確認した。
浮動小数は探索の順序にのみ使い、採用する不等式は厳密に検査する。

### 検討した別の区間型（今回の閉包では不使用）

全凸包を32分割する帯域では、上述の3反復枝の極限点は正規化座標で約0.17219126にあり、
広い比の版でもこの点を含む帯域は残らない。
これを真の穴とするには根拠が足りない。未被覆小区間の中点を追加長の和80まで
厳密な外側円筒で追っても、今回の7点はいずれも除外できなかった
（`endpoint_outer_gap_test.json`）。これは充填の証明でもない。

この枝に適した別の具体的な型は、
\[
t_3=\frac{\sqrt{13}-3}{2},\quad
z_3(a,b)=F_a(t_3)+F_b(t_3),\quad D_a=|F_a'(t_3)|,
\]
\[
\widetilde J_{\alpha,\beta}(a,b)
=[z_3(a,b)-\alpha D_a,\ z_3(a,b)+\beta D_a],\qquad \alpha,\beta>0
\]
である。これは次の探索候補であり、被覆が証明された型ではない。
区間が全円筒の凸包に入るように \(\alpha,\beta\) を選ぶ条件も加える。
\(t_3\) を尾として許せる状態に限れば、\(33|33\) の後続で
\[
z_3(a33,b33)=z_3(a,b),\quad
D_{a33}=\eta D_a,\quad
\frac{D_{b33}}{D_{a33}}=\frac{D_b}{D_a},\qquad
\eta=t_3^4=\frac{119-33\sqrt{13}}2
\]
が厳密に成立する。
従って、この型の Lem2 に残る具体的な条件は、正規化した二つの外側部分
\[
[-\alpha,-\eta\alpha]\ \cup\ [\eta\beta,\beta]
\]
を既に閉じた一般族に戻る後続で覆うことである。
中央部分は同型の \(33|33\) 後続が覆う。
全凸包の端点から測る帯域とは異なり、特別な戻りの中心と縮小率を固定できる。
この外側部分の一様な被覆はまだ得ていない。
実際に得られた下端の閉包では、元の \(J_{p,q}\) 型を保ち、
深い後続を適応的に探索して、箱全体での区間どうしの重なりを直接検証する方法を使った。
