## 相関を保持しても残る偽の一様義務

`audit_chart_gaps.py` を追加した。チャートの基底領域の中点・頂点を選び、
その点を有限語の変換で厳密に移す。独立した円柱列挙検証器で、
要求区間内にある開区間がどの合法円柱和とも交わらないことを確認する。
探索時だけ浮動小数を使い、受理と再検証は `Q(sqrt(462))` の厳密演算で行う。

続行途中の部分戦略で参照数の多い未解決32型を調べ、8型を反証した。
元の節点番号は `1950, 1949, 2117, 1951, 1263, 1628, 2131, 786`。
深さ4または5の有限円柱列挙で、各隙間を厳密に証明した。

さらに、条件付き規則と左右交換を含む**全入辺**を逆算した。
8反例点はすべて、保存戦略の初期節点から到達不能だった。
6件は直前の親ですでに除外され、残る2件ももう一段さかのぼると除外された。
深さ上限に達した点を除外済みとは扱っていない。
この逆算は初期族全体の充填も、他の表示方法の不存在も主張しない。

領域縮小後の上位32型にも8個の隙間を検出し、全反例点が逆算で除外された。
一つの箱へ入辺の像をまとめるだけでは、到達不能な点がなお混入する。
したがって、保存された未解決義務をすべてそのまま証明する方針には実際の障害がある。

## 入辺ごとの領域分離

`split_chart_incoming.py` を追加した。反証された未解決型について、
親から来る像と旧領域との共通部分を、それぞれ別の未解決型として保持する。
同じ領域は共有し、異なる入辺の像の凸包を再び取らない。
不要な到着先を除くときにも、共通座標系で全像を被覆できることを検査する。
根の全領域は変更しない。

すべての親規則・初期族・剪定後の規則を独立に再検証する。
この処理は節点数を増やしうる。新しい子を証明済みとは扱わない。
また、入辺の像自体を外側の箱で評価するため、これだけで全反例が消える保証はない。

実データでは54個の子型を生成し、65参照を付け替え、不要な4参照を除いた。
到達不要な旧型の除去後は2,894型・1,071局所規則・未解決1,823件。
既知の8反例点のうち6点が、対応する置換後の全義務から除かれた。
元の節点 `1263` と `786` の2点はそれぞれ新節点 `2846` と `2843` に残る。
これらは逆算でももう一段の親を必要とした2点であり、単一段の分離の限界が具体的に分かる。
6点の除去は、その6族の充填を証明したという意味ではない。

## 再実行と次の作業

以下はこのディレクトリ内で実行する。

```sh
python3 audit_chart_gaps.py continued_mosaic_seed.json \
  --verify --output continued_chart_gaps.json
python3 audit_chart_gaps.py continued_reduced.json \
  --limit 32 --backward-depth 6 --output continued_reduced_gaps.json
python3 split_chart_incoming.py continued_mosaic_seed.json \
  --gaps continued_chart_gaps.json --output continued_incoming_split.json

python3 search_hybrid_induction.py \
  --graph continued_reduced.json --search-state continued_reduced.state.json \
  --complete-state hybrid_induction_20260924_finish.state.json \
  --seconds 180 --output continued_next.json
```

最後のコマンドは、改善した部分戦略に探索を切り替えつつ、全列挙の番号を保持する。
元の二経路をそのまま再開するなら `--resume hybrid_induction_20260924_finish.state.json` を使う。
ただし再結合側の固定候補は一巡済みなので、そのままでは子型生成中心になる。

次の課題は、入辺ごとの分離でも残る反例点に対し、親側の領域分離を伝播するか、
入辺の像を外側の箱ではなく相関を持つチャートのまま子に渡すことである。
単に語長上限を増やすことでは、反証済みの一様義務そのものは修復できない。
