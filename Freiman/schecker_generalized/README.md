## 1. 定義と今回の実装範囲

語は、左右とも中心から外向きに読む。`U|V` の物理的な中央ブロックは
`rev(U) 4 V` である。今回の実装では

- 固定接頭語の数字は `1,2,3,4`;
- 新たに付ける数字は `1,2,3`;
- 禁止語は左右とも `31313`;
- 禁止は、固定接頭語と追加部分を合わせた一方向の語全体に課す。

とする。`3-後続` は「追加桁が3以下」の意味であり、後続がちょうど3個という意味ではない。

`K_B(U)` を、この条件で接頭語 `U` を持つ連分数の集合とする。
ユーザーの一般の定義は

\[
S(A;B_1,B_2)=
(K_{B_1}(U)+K_{B_2}(V))\cup(K_{B_2}(U)+K_{B_1}(V)),
\qquad I(A;B_1,B_2)=\operatorname{conv}S(A;B_1,B_2)
\]

と書ける。非空の場合を考える。有限アルファベットなので各集合はコンパクトで、端点は達成される。
ただし **`S=I` は定義には含まれない**。異なる割当ての2集合の間にも凸包だけの隙間がありうる。
本プログラムが計算するのは `B_1=B_2={31313}` の場合のみで、任意の禁止集合用の実装ではない。

### 元のT区間との対応には注意が必要

`Schecker/doc/schecker.tex` のT区間は、固定接頭語を任意に保ったまま、
その後ろに `C(2)` と `C(3)` の末尾を左右交換して付けた和の凸包である。
禁止を固定接頭語にまで課す今回の定義とは、そのままでは一致しない。

さらに、共通アルファベットを `{1,2,3,4}` として**末尾だけ**に禁止を課すなら、
`C(2),C(3)` に対応するのは `{3,4},{4}` である。
`{3,4},{3}` だと後者は数字 `{1,2,4}` の集合になる。
新規桁を最初から `{1,2,3}` に制限する場合には、対応する禁止集合は `{3},∅`。
ここは「一般化」の定式化時に直す必要がある。今回の反例計算は上記の明示的な3後続の設定で行った。
新規桁に4以上も許す集合についての反例だとは主張しない。

## 2. 極値は5状態オートマトンで厳密に計算できる

既読語の接尾辞のうち、`31313` の真の接頭語として最長のものを状態にする。

| 状態 | 次が1 | 次が2 | 次が3 |
|---|---|---|---|
| 空 | 空 | 空 | 3 |
| 3 | 31 | 空 | 3 |
| 31 | 空 | 空 | 313 |
| 313 | 3131 | 空 | 3 |
| 3131 | 空 | 空 | 禁止 |

どの合法な遷移も、その後に2を無限に付ければ継続できる。
したがって連分数の交代順序に従って、最大値なら奇数桁で最小、偶数桁で最大の合法数字を選べばよい。
最小値は逆。状態と偶奇の組が有限なので、極値の語は最終的に周期的になる。

例えば空状態からの最小・最大は

\[
V=[0;\overline{313121}]=\frac{-29+2\sqrt{462}}{53},\qquad
T=[0;\overline{131312}]=-1+\frac{\sqrt{462}}{12}.
\]

各接頭語の極値は、これらを含む周期末尾にその接頭語のMöbius変換を施して得られる。
今回の全端点は `Q(√462)` に属する。
`explore.py` は `a+b√462` の有理係数を保持し、符号を有理数の平方比較で判定する。
出力の小数は表示用のみ。連結・包含・隙間の判断に許容誤差は使わない。

 g_+=T_{31311}(T)+T_{31312}(T)

という端点が現れ、厳密に `g_-<g_+` となる。

\[
\begin{aligned}

g_+&=0.5281628167714426031300\ldots.

## 4. 直後の連結性を加えても閉じない

試した候補を

\[
\rho_B(A)=\frac{|\operatorname{conv}K(V)|}{|\operatorname{conv}K(U)|},\qquad
\mathcal G_1(A):\quad
5/17\le\rho_B(A)\le17/5,
\quad\text{両側各1桁の全子凸包の和集合が連結}
\]

とする。`ρ_B` は旧 `v` とは違う。
この条件を満たす、総追加長3以下の後続で親を被覆する探索は、例えば次を返す。

| 親 | 左右への追加語の組 |
|---|---|
| `321|431` | `(1,ε), (2,ε), (3,ε)` |
| `32112|4322` | `(1,ε), (2,ε), (3,1)` |
| `32113|4323` | `(1,ε), (2,ε), (3,1)` |
| `32113|4322` | `(1,ε), (2,1), (3,1)` |

しかし最後の親の子 `321133|43221` は `G_1` を満たすにもかかわらず、両側3桁で

\[
(0.5279697569985717440283\ldots,
 0.5279697635791751148360\ldots)
\]

という真の隙間を持つ。
したがって、`G_1` を満たすすべての区間に後続被覆補題を適用することはできない。

ここでの失敗は、親 `32113|4322` 自身にこの隙間があるという意味ではない。
別の子との重なりを使えば当該部分を埋められる可能性がある。
この「重なっている子のどちらを選ぶか」が、履歴や目標値を持つ方法を検討する理由である。

## 5. 厳密な外側近似と、有限検証の限界

`E_n(U)` を、`U` に合法な数字をちょうど `n` 個付けた接頭語の集合とし、

\[
O_n(U,V)=\bigcup_{u\in E_n(U),\ v\in E_n(V)} I(u\mid v)
\]

とする。実装の `outer_components` がこれを正確に計算する。

- `S(U,V) ⊂ O_{n+1}(U,V) ⊂ O_n(U,V) ⊂ I(U|V)`。
- `O_n` の隙間は、無限の和集合にも存在する。
- **`S(U,V)=⋂_{n≥0}O_n(U,V)`**。

最後の等式は、両側の長さが `n` 増えた円柱の直径が一様に0へ行くことから従う。
より具体的には、`t∈O_n` を含む子凸包を選び、その子の合法な実現値 `s_n` を一つ選ぶ。
`|t−s_n|` は子凸包の直径以下で0へ行く。
親の真の和集合はコンパクトなので `t` もそこに属する。
この証明では、選ばれた子が世代間で入れ子である必要はない。

従って「ある深さで隙間がある」は証明になるが、
「ある有限の深さまで隙間がない」は充填の証明にはならない。

## 6. 端点を固定する初期区間族――次に優先して調べたい構造

\[
P=313121,\quad U_n=3211P^n3,\quad V_n=4322P^n,\quad
J_n=4+I(U_n\mid V_n).
\]

**命題。** すべての `n≥0` について、ある `b_n` により

\[
J_n=[c_F,b_n],\qquad b_{n+1}<b_n,\qquad b_n\downarrow c_F
\]

となる。ただし、これは凸包の命題であって、その内部の実現をまだ意味しない。

**証明。** `U_n` の末尾状態は3で長さは奇数、`V_n` は空状態で長さは偶数。
状態3からの最大末尾は `[0;overline(131213)]`、空状態からの最小末尾は
`ξ=[0;overline(P)]`。従って両側の最小値を与える無限語は、どの `n` でも

\[
3211\overline P,\qquad4322\overline P
\]

である。直接計算すると

\[
4+T_{3211}(\xi)+T_{4322}(\xi)
=\frac{2221564096+283748\sqrt{462}}{491993569}=c_F.
\]

次の接頭語は

\[
(U_{n+1},V_{n+1})=(U_n\,131213,\ V_n\,313121)
\]

だから、両側の集合は入れ子である。
親の上端を実現する末尾と、最小値側へ進むこれらの追加語は異なり、
交代順序の厳密性とコンパクト性により上端は厳密に減少する。
両側の接頭語長が発散するので幅は0へ行く。□

| `n` | `b_n` の概数 | 旧 `v(U_n,V_n)` の概数 |
|---|---:|---:|
| 0 | 4.5280046477223012887392 | 0.6228638166 |
| 1 | 4.5278295888845761056555 | 0.5644838526 |
| 2 | 4.5278295661639523867594 | 0.5644767291 |
| 3 | 4.5278295661608795565232 | 0.5644767281 |

これら4例の `O_4` はいずれも連結だった。全 `n` や全深さに関する証明ではない。

この族により、端点近くで必要な初期被覆を

\[
[c_F,b_0]=\{c_F\}\cup\bigcup_{n\ge0}[b_{n+1},b_n]
\]

に整理できる。**各帯 `[b_{n+1},b_n]` を、帰納的に検証可能な短い後続区間で埋める**
という問題を優先したい。これが成功すれば、端点近傍の初期族を単純化できる可能性がある。
帯の充填も、そのための有限テンプレートも、まだ得られていない。

無限の `n` は数値的に打ち切る必要がない。

\[
M(P)=\begin{pmatrix}14&19\\53&72\end{pmatrix},\quad M(P)^2=86M(P)-I,
\]

より、`n≥1` に対し

\[
M(P)^n=u_n(M(P)-x_nI),\quad
u_0=0,\ u_1=1,\ u_{n+1}=86u_n-u_{n-1},\quad
x_n=\frac{u_{n-1}}{u_n}\in[0,1/85].
\]

共通の正の係数はMöbius変換から消える。
したがって `n=0` を別扱いし、残りを `x∈[0,1/85]` 上の一様不等式として証明する設計が可能。
この行列パラメータ化自体は既存のFreiman資料にも使われている。

## 7. 保持すべきSchecker型の補題

次の形なら、証明の骨格をそのまま使える。

**目標値付き後続被覆補題（十分条件）。**
節点を `(A,σ)` とし、`σ` は禁止語状態、偶奇、必要な履歴などを表す。
各節点に閉集合 `D(A,σ)⊂I(A)` を割り当てる。
ここでは `D` は1区間でも有限個の区間の和でもよい。

次を証明できたとする。

1. 初期節点の `a_0+D(A,σ)` と、別途実現した極限値が目的の範囲を覆う。
2. 各節点には合法なproper 3-後続が指定され、
   `D(A,σ) ⊂ ⋃ D(A',σ')`。別途実現した点に達して終了してもよい。
3. 指定された無限経路では左右両方の接頭語長が発散する。

このとき初期のすべての目標値を、合法な左右の無限継続による和として実現できる。

**証明。** 同じ `t` を含む子を順次選ぶ。有限接頭語は入れ子で、禁止語を作らない。
両側の長さの発散によって、それぞれ唯一の無限語に収束する。
`t` とその和はどの段階でも同じ円柱凸包内にあり、その直径は0へ行く。□

元のSchecker型は、許容節点では `D(A,σ)=I(A)` とする特別な場合。
まずこの形で、禁止語状態とパラメータに依存する許容領域を探す価値はある。
ただし今回の反例から、その領域の外の節点は丸ごと使用できない。

丸ごとの区間では閉じなければ、必要な部分だけ `D` を縮める。
ある子が親の一部を埋められなくても、そこを先に別の子へ割り当てればよい。
履歴を使う場合の本当の条件は

\[
\text{「この履歴で到達し得る目標値」}\subseteq
\bigcup\text{「合法な子で扱える目標値」}
\]

である。`J(A)` 全体を無条件に被覆すると言い換えてはいけない。

第3条件は重要で、単に「総追加長が毎回増える」だけでは足りない。
例えば旧の全幅比を正の上下定数の間に保つこと、または
「現在の広い側を高々一定ステップ以内に必ず伸ばす」ことから証明できる。

## 8. 許容性の探索に必要なパラメータ

\[
M(U)=\begin{pmatrix}a_U&b_U\\c_U&d_U\end{pmatrix},\quad
r=c_U/d_U,\quad s=c_V/d_V,\quad q=d_U^2/d_V^2,
\quad G_r(x)=\frac{x}{1+rx}.
\]

`ε_U=(-1)^|U|`, `ε_V=(-1)^|V|` とすると、定数項と正の尺度を取り除いた和は

\[
F_A(x,y)=\varepsilon_U G_r(x)+q\varepsilon_VG_s(y).
\]

旧比率は `α=[0;overline(31)]`, `β=[0;overline(13)]` を使って

\[
v(A)=q\frac{(1+r\alpha)(1+r\beta)}{(1+s\alpha)(1+s\beta)}.
\]

一つの数 `v` に圧縮すると、`r,s` と禁止語状態ごとの端点配置が失われる。
自然な探索状態は

\[
(\text{左の禁止語状態},\text{右の禁止語状態},
\varepsilon_U,\varepsilon_V,r,s,q)
\]

であり、必要に応じて目標値の領域や有限履歴を加える。
任意の有限禁止語集合にも、真の接頭語を状態にした有限オートマトンで同じ考え方を使える。
`B_1≠B_2` では左右への割当ても保持する。

`M(u)=(a_u,b_u;c_u,d_u)` と書くと、後続による更新は

\[
r'=\frac{ra_u+c_u}{rb_u+d_u},\quad
s'=\frac{sa_v+c_v}{sb_v+d_v},\quad
q'=q\frac{(rb_u+d_u)^2}{(sb_v+d_v)^2}.
\]

特に左に数字 `a` を一つ付ければ `r'=1/(a+r)`, `q'=q(a+r)^2`。
Freimanの初期語からは `1/4≤r,s≤4/5` を保てる。

端点の比較、隣の子との接触、親の端の被覆、更新後の許容領域への包含を、
正の分母を払った多項式不等式にする。
そのうえでパラメータ箱を分割し、区間演算やBernstein係数の符号で一様に証明する。
サンプル点での成功を箱全体に拡張したと見なしてはいけない。

実装に進む際の順序:

1. 今回の exact engine で、初期語やその後続から反例と短い被覆候補を収集する。
2. `I(A)` 全体を扱える状態領域を探索する。子も同じ領域に入ることまで要求する。
3. 無理な領域では、反例の隙間を含まない区間片 `D(A,σ)` と目標値の割当てを導入する。
4. 選んだ有限テンプレートを、`r,s,q` の箱全体で検証する。
5. 端点近傍は第6節の帯で検証するか、既存の初期族を使用する。
6. 左右長の発散、境界の等号、周期極限点を別々の証明義務として確認する。

有限テンプレートで十分なことは未証明。
既存のFreiman法が使う可算の後続族も許し、その場合は周期極限点を明示的に処理する方針が安全である。

## 10. 和の実現からLagrangeスペクトルへ

和が埋まったことだけでは、Lagrangeスペクトルへの包含はまだ従わない。
中心以外のPerron値の上限が必要である。

数字 `1,2,3` の背景で `31313` を禁止すると、局所値の上限は

\[
c_* = 4\sqrt{462}/19 < \kappa=113195/25000 < c_F.
\]

4を含む場合でも、`14,41,31313` を禁止すれば、中心数字が3以下の場所には同じ上限を使える。
理由は、3の両隣が1でなければ局所値は `9/2` 未満、
両隣が1なら距離2の少なくとも片側は2以下であることによる。
状態3からの最大末尾 `U=(2√462−28)/19` と、制約側の最大末尾
`T_12(T)=(2√462−29)/19` を足すと上の `c_*` になる。
4を許しても、これらの極値から最初に大きくなる候補は `14` または `31313` を作るので排除される。

7初期ブロックの継続では `14,41` は現れない。
2個目の4がある4種類については、中心0の左末尾を `x`、中心1の右末尾を `y` とすると

\[
\lambda_1=4+y+\frac1{4+x}
\le4+\max K(V\text{の最初の4を除いた語})
       +\frac1{4+\min K(U)}.
\]

今回の exact engine で再計算した上限は次のとおり。

| 接頭語 | 2個目の4での上限 |
|---|---:|
| `321|431` | 4.5138676746040380244605… |
| `32112|4322` | 4.5261151084538022138517… |
| `32113|4323` | 4.5240750531008274723917… |
| `32113|4322` | 4.5261277597156722408425… |

どれも厳密に `κ` 未満。
従って、これらのブロックから `t≥c_F` を和として実現できれば、中心値が全体の最大になる。

Lへの実現は、得られた両側語の増大する中央部分を、区切りの2を挟んで繰り返し並べればよい。
コピーの中心ではPerron値が `t` に近づく。
中心から有限距離の極限は元の語のシフトで、その他の極限は4のない禁止語回避の背景語になる。
区切りの2は `31313` を作らない。従って他の極限値は `t` 以下で、limsup はちょうど `t`。
この議論は `t=c_F` にも使える。
第6節の周期的な極値語によって `c_F∈L` 自体はこの段階で示せるが、近傍全体の充填とは別である。

下側 `[c_F,√21]` をこのように実現できれば、上側はScheckerの定理に接続できる。
ただしリポジトリのScheckerの有限探索だけを、普遍的な被覆補題の証明の代わりにしてはいけない。

## 11. 再実行

リポジトリのルートで:

```sh
python3 Freiman/schecker_generalized/explore.py --output Freiman/schecker_generalized/results.json
python3 -m unittest discover -s Freiman/schecker_generalized -v
```

Python標準ライブラリのみ。Sage/SymPyやネットワークは不要。
`--root-depth` は1から4まで。既定値は4。

対話的な探索例:

```python
import sys
sys.path.insert(0, 'Freiman/schecker_generalized')
from explore import *

# 真の和集合を含む外側近似。出力に隙間があれば厳密な反例。
outer_components('3131', '3131', depth=1)

# 指定した候補許容条件による、有限の後続被覆を探索。
# 成功しても許容条件の普遍的な帰納性は意味しない。
has_cover('32113', '4322', depth=3, predicate=locally_good)
```

`results.json` に端点の有理係数と小数、初期7ブロックの分割、
反例、短い被覆、周期初期族の有限サンプルを保存する。

テストは、オートマトンを有限語の文字列検索で確認し、周期極値を別実装の有理数円柱で挟み、
端点の包含、反例、返された被覆、`c_F` の厳密恒等式を検証する。
追加した端点型探索の検証を含め18テストが通過。すべての無限経路の被覆を検証するテストではない。
