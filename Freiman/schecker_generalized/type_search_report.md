# 端点型の探索結果：短縮型1種類による一様初期被覆と、4種類の候補

## 結論と証明の範囲

実際に端点型を列挙し、後続による被覆を探索した。
今回の最も具体的な成果は、次の**全指数に対する局所被覆の証明**である。

\[
\boxed{
I(U_n\mid V_n)
=I(U_n1\mid V_n)\cup I(U_n2\mid V_n)\cup J(U_n\mid V_n1)
\quad(n\ge0).
}
\]

ここで `U_n=3211(313121)^n3`, `V_n=4322(313121)^n`、`J` は下端を1つの明示的な値に置き換える型。
定義と短い証明を第1節に記す。

さらに、次の候補が得られた。

- 全凸包と、端点の組として4種類の型（および左右交換）を使う。
- 1回の後続で追加する総桁数を2以下まで許す。
- `A_0=32113|4322` 全体について、どの経路も総追加桁数8以上になる有限被覆を厳密に検証した。

**まだ普遍的な許容条件は得られていない。**
一様初期被覆の子区間がすべて埋まること、有限被覆の末端から無限に同じ型で続けられることは未証明。
今回の成果を `[c_F,∞)⊂L` の新証明と解釈してはいけない。

## 1. 得られた簡単な型と、一様被覆の証明

以下、追加桁は `1,2,3`、禁止語は `31313`、語は中心から外向きに読む。
`T_W(x)` は接頭語 `W` のMöbius変換、`I` は合法な和集合の全凸包。

\[
\xi=[0;\overline{313121}]=\frac{-29+2\sqrt{462}}{53},\quad
T=[0;\overline{131312}]=-1+\frac{\sqrt{462}}{12},\quad
\zeta=[0;\overline{131213}]=\frac{2\sqrt{462}-28}{19}.
\]

`ξ,T` は空状態からの最小・最大末尾、`ζ` は状態3からの最大末尾である。

### 短縮型の定義

`U,V` の長さがともに奇数で、禁止語状態がそれぞれ3、空状態の場合に、

\[
\boxed{
J(U\mid V)=
\left[T_{U2}(\xi)+T_{V1}(\xi),\ \max I(U\mid V)\right]
}
\]

とする。上端は全凸包と同じで、下端だけを変える。
この状態では

\[
\max I(U\mid V)=T_{U3}(\zeta)+T_{V3}(\zeta).
\]

どちらの端点も合法な継続による和である。従って下端は上端以下であり、`J⊂I`。
ただし、内部の充填はまだ結論していない。

### 命題

\[
U_n=3211P^n3,\quad V_n=4322P^n,\quad P=313121
\]

とすると、すべての `n≥0` について冒頭の3区間被覆が成り立つ。
ここで `U_n` は奇数長・状態3、`V_n` は偶数長・空状態なので、
`J(U_n|V_n1)` には上の定義を適用できる。
3つの区間はいずれも親のproper 3-後続に付随する。

### 証明

定数項を引き、`d_{U_n}^2` 倍して正規化する。

\[
r=\frac{c_{U_n}}{d_{U_n}},\quad s=\frac{c_{V_n}}{d_{V_n}},\quad
q=\frac{d_{U_n}^2}{d_{V_n}^2},\quad G_r(x)=\frac{x}{1+rx}.
\]

正規化された和は `-G_r(x)+qG_s(y)`。
以下の範囲を全 `n` に対して示せる。

\[
\frac14\le r\le\frac3{10},\qquad
\frac25\le s\le\frac34,\qquad
\frac23\le q\le\frac56. \tag{1}
\]

`a=T_{11}(ξ)`, `b=T_2(ξ)` とおく。
3区間を順に `H_1,H_2,J_1` とする。

**外側の端点。** 状態ごとの極値の最初の桁を読むと、

\[
\min H_1=\min I(U_n\mid V_n),\qquad
\max J_1=\max I(U_n\mid V_n).
\]

後者には `T_3(ζ)=ξ`, `T_{13}(ζ)=T` を使う。

**`H_1` と `H_2` の接触。** 正規化した上端−下端は

\[
\max H_1-\min H_2
=-\frac{a-b}{(1+ra)(1+rb)}
+q\frac{T-\xi}{(1+sT)(1+s\xi)}.
\]

`a>b`、`T>ξ` なので、(1)からこれは

\[
-\frac{a-b}{(1+a/4)(1+b/4)}
+\frac23\frac{T-\xi}{(1+3T/4)(1+3\xi/4)}
\]

以上。この値は厳密に正であり、約 `0.092018885010653…` である。
**この余裕は正規化座標での値**で、元の座標では `d_{U_n}^2` で割る。

**`H_2` と `J_1` の接触。** 正規化した差は

\[
\max H_2-\min J_1
=G_r(T_2(\xi))-G_r(T_2(T))
+q\bigl(G_s(T)-G_s(T_{11}(\xi))\bigr)>0.
\]

`T_2(ξ)>T_2(T)` と `T>T_{11}(ξ)` により両項とも正。
各区間は親の凸包内にあり、`H_1` は親の下端から、`J_1` は親の上端まで達する。
2つの接触によって合併が連結になり、親全体を覆う。

**範囲(1)の証明。** `n=0` は

\[
(r,s,q)=(17/61,\ 30/73,\ 3721/5329)
\]

で直接確認する。`n≥1` は

\[
M(P)^n=u_n(M(P)-x_nI),\quad
M(P)=\begin{pmatrix}14&19\\53&72\end{pmatrix},\quad
0\le x_n<1/85
\]

と表す。ここで `u_0=0,u_1=1,u_{n+1}=86u_n-u_{n-1}`、`x_n=u_{n-1}/u_n`。
正の係数 `u_n` は消えるので、

\[
M(U_n)\sim M(3211)(M(P)-xI)M(3),\quad
M(V_n)\sim M(4322)(M(P)-xI)
\]

を `0≤x≤1/85` で調べればよい。
各成分は `x` の一次式で、この範囲で正。
`r,s` と正の比 `d_{U_n}/d_{V_n}` は一次分数関数なので単調または定数であり、
その正の平方である `q` も単調または定数。
両端 `x=0,1/85` で(1)を有理数計算で確認すれば、全区間について従う。□

この証明は `uniform_initial_cover.py` と `uniform_initial_cover.json` に対応する。
極値の恒等式、一次式の端点での正値、範囲(1)、接触の正の下限を厳密に再計算する。
有限サンプル `n=0,1,2,3` は整合性確認用であり、無限の `n` の代わりには使っていない。

### 次に調べるべき3つのパラメータ領域

被覆の証明自体は、`A_n` に限らず、左が奇数長・状態3、右が偶数長・空状態で、
(1)に入る任意の接頭語に成り立つ。従って1つの許容領域について局所被覆を得たことになる。
子のパラメータは次の箱に入る。これらが再び許容的であることは未証明。

| 子 | 状態 | 偶奇 | `r'` | `s'` | `q'` |
|---|---|---|---|---|---|
| `I(U1,V)` | `31,空` | 偶・偶 | `[10/13,4/5]` | `[2/5,3/4]` | `[25/24,169/120]` |
| `I(U2,V)` | `空,空` | 偶・偶 | `[10/23,4/9]` | `[2/5,3/4]` | `[27/8,529/120]` |
| `J(U,V1)` | `3,空` | 奇・奇 | `[1/4,3/10]` | `[4/7,5/7]` | `[32/147,125/294]` |

これは左に数字 `a` を付ける更新 `r'=1/(a+r), q'=q(a+r)^2`、
右に1を付ける更新 `s'=1/(1+s), q'=q/(1+s)^2` から直ちに従う。
最初からすべての状態を探索するより、まずこの3領域の後続被覆を調べるとよい。

## 2. 端点型をどう探索したか

状態 `s` からの極値末尾を `ξ_s^-`, `ξ_s^+` と書く。
左側の候補は

\[
L_i^\pm(U)=T_{Ui}(\xi_{s(Ui)}^\pm),\qquad i\in\{1,2,3\}
\]

で、右側にも `R_j^±(V)` を作る。禁止語を作る `i,j` は除く。
**ここで±は追加語の後ろに付ける末尾の大小であり、Möbius変換後の値の大小とは限らない。**

最初の探索では最大36個の和 `L_i^ε+R_j^δ` を端点候補にし、
子の候補区間の合併に含まれるように親の端点を内側へ丸めた。
各段階の幅比は、制限付きの片側凸包の幅の比 `ρ_B` で

\[
1/20\le\rho_B(A)\le20
\]

とした。この比率条件自体が許容性の十分条件だとは考えていない。
片側だけの発散を防ぎつつ候補を探索するための範囲である。

幅比を `1/5…5` にすると、強制される極値側への延長の途中で候補を落としやすかった。
初期 `A_0` では10段階後に残る幅が親の約37.5%となる。
範囲を `1/20…20` に広げた一般の端点候補探索では、`A_0` 全体が10段階まで残った。
これらは浮動小数点による探索結果で、充填の証明ではない。

探索した有限被覆については、選んだ端点の記号を保存して、
`Q(√462)` の符号比較だけで被覆を再検証した。
この再検証は探索側の浮動小数点の判定を参照しない。

## 3. 4種類の端点形状

`A_0,A_1,A_2` の6桁先までの厳密な有限被覆から、
全凸包以外の端点形状を、左右交換と端点の順序を同一視して分類したところ、次の4種類になった。

| 型 | 一方の端点 | 他方の端点 |
|---|---|---|
| `J1` | `L_1^- + R_3^+` | `L_3^+ + R_2^-` |
| `J2` | `L_1^- + R_2^-` | `L_3^+ + R_3^+` |
| `J3` | `L_1^- + R_2^+` | `L_3^+ + R_1^-` |
| `J4` | `L_1^- + R_1^-` | `L_2^+ + R_3^+` |

2端点の小さい方を下端、大きい方を上端とする。左右交換も許す。
第1節の短縮型は、該当する状態・偶奇での `J2` の左右交換にあたる。

これは端点の**形状**が4種類という意味である。
禁止語の末尾状態と偶奇による区別は別に必要で、全状態の証明義務が4個という意味ではない。

### 一桁ずつの後続では4種類だけに閉じない

4種類と全凸包だけに候補を固定し、片側に1桁だけ追加する後続を使って、
可能な被覆を各世代で全部検査した。

- `A_0` 全体は6段階まで残る。
- 7段階目には候補区間が空になる。

この結果は `exact_shape_search.py` で厳密に確認し、`four_shapes_exact.json` に保存した。
13,523個の `(U,V,残り深さ)` を処理している。

これは、**この4形状・この幅比範囲・片側一桁という遷移規則では**閉じた帰納系を作れないという結果。
`A_0` の真の和集合に穴があるという意味ではない。
候補端点に制限があるので、表せる点を探索側が落としている可能性がある。

8桁の一般端点探索から形状を追加すると8種類になり、
浮動小数点の再探索では8段階まで `A_0` 全体が残るが、9段階目に約87.7%へ縮む。
型を増やすだけで閉じることは、まだ確認できない。

### 一度に2桁まで追加できる後続なら、4種類で先へ進める

同じ4種類のまま、総追加長1または2の合法な後続をすべて許した。
2桁の途中の接頭語には型や幅比条件を課さず、選ぶ子だけに課す。
追加語内部や境界で禁止語を作ることは許さない。

この設定で `A_0` 全体から、**どの経路でも総追加桁数8以上**まで進む被覆を厳密に検証できた。
「4段階で最大8桁」という異なる条件ではない。
残り深さを実際の追加桁数だけ減らし、すべての末端が必要な深さに達したことも検証している。

証明書 `four_shapes_step2_certificate.json` の規模:

- 節点1,594個、後続への辺1,656本。
- 末端の全凸包846個は、充填を未証明のまま残している。
- 末尾状態・偶奇まで含めた端点型は117種類。

この有限結果から、**型を増やし続ける前に、短い複数桁の後続で中間状態を飛び越える**
方針を優先したい。Scheckerの3-後続は追加桁が3以下という意味なので、2桁追加してもその枠内である。
ただし、同じ4種類で無限に継続できることは未証明。

浮動小数点の探索では、同じ4形状・2桁後続で総追加深さ10まで `A_0` 全体が残った。
この10桁の結果は探索段階であり、厳密な有限証明書は8桁まで。

## 4. 証明書の意味

`type_certificates.py --verify` は以下を確認する。

1. 根は指定された接頭語の全凸包。
2. 各端点は、合法な追加語と状態ごとの周期末尾から厳密に得られる。
3. 各子は親の合法なproper 3-後続で、指定された総追加長の上限内。
4. 子の区間の合併が親の区間全体を覆う。端点の接触も厳密に判定する。
5. 残り深さが規定どおり減り、葉は明示的な全凸包。
6. 型を4種類に制限した証明書では、実際にその型または全凸包しか使っていない。
7. 全節点で `1/20≤ρ_B≤20`。

葉を「許容的だから充填済み」とはしていない。
有限の証明書だけでは、無限の経路が存在することを結論できない。

一般の端点探索の証明書も保存した。

|---|---|---:|---:|---:|
| `type_certificate.json` | `A_0,A_1,A_2`、各6桁 | 968 | 1003 | 510 |
| `type_certificate_depth8.json` | `A_0`、8桁 | 1670 | 1734 | 884 |
| `four_shapes_step2_certificate.json` | 4形状・2桁後続、`A_0`、8桁 | 1594 | 1656 | 846 |

## 5. 次に必要な探索・証明

次に必要なのは、単に深さを増やすことよりも、
4形状の各々に対して「どの `r,s,q` なら、同じ形状群の短い後続へ移れるか」を明示すること。

具体的な証明義務は以下。

- 初期の3区間被覆で現れた2つの全凸包と短縮型について、パラメータ領域を定める。
- 各領域で、総追加長2程度の後続リストが一様に被覆することを示す。
- 各子の更新後のパラメータが、いずれかの許容領域に入ることを示す。
- 禁止語の末尾状態、偶奇、左右交換を含めて場合を尽くす。
- 端点 `c_F` に達する周期経路も境界条件として含める。

今回証明した初期被覆では、接触の比較を広い有理数の箱で処理できた。
同じ程度の粗い箱と少数の分岐条件で後続も閉じれば、人間が追える証明になる。
それが不可能な状態に限って、新しい端点形状や3桁以上の後続を追加するのがよい。

## 6. 再実行

すべてリポジトリのルートから実行する。Python標準ライブラリのみ。

```sh
# 全 n に対する初期被覆の厳密計算
python3 Freiman/schecker_generalized/uniform_initial_cover.py

# 保存済み有限被覆の厳密リプレイ
python3 Freiman/schecker_generalized/type_certificates.py --verify Freiman/schecker_generalized/type_certificate.json
python3 Freiman/schecker_generalized/type_certificates.py --verify Freiman/schecker_generalized/type_certificate_depth8.json
python3 Freiman/schecker_generalized/type_certificates.py --verify Freiman/schecker_generalized/four_shapes_step2_certificate.json

# 4形状・一桁後続の候補消滅を厳密に再計算
python3 Freiman/schecker_generalized/exact_shape_search.py --bank 4 --depth 7

# 4形状・総追加長2以下での浮動小数点探索
python3 Freiman/schecker_generalized/search_shape_bank.py --bank 4 --max-step 2 --depth 8 --root-only

# 同じ設定の有限被覆を生成し、その場で厳密検証
python3 Freiman/schecker_generalized/type_certificates.py --bank 4 --max-step 2 --depth 8 --n-max 0

# 全テスト
python3 -m unittest discover -s Freiman/schecker_generalized -v
```

`search_types.py` は候補端点を広く取る探索。
`search_shape_bank.py` は4形状または8形状に限定する探索。
浮動小数点探索には小さな比較許容差があるため、その結果を証明に用いる前に必ず厳密リプレイする。
`exact_shape_search.py` と証明書のリプレイには、その許容差を持ち込まない。
