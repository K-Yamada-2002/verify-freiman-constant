## 帰納命題

固定した目標値を `t` とし、深さ `d` の状態を次の情報で定める。

1. 物理的な外向き接頭語 `(U_d,V_d)` は許された初期ブロックを保ち、追加桁は1,2,3、禁止語31313を含まない。
2. 全3桁円柱の幅で広い側を決める。普通の短縮被覆 `J(U_d,V_d)` は良い。
3. `t ∈ J(U_d,V_d)`。すべての段階で同じ `t` を使う。
4. それまでの選択は指定された優先順位に従う。
5. 印付き接尾辞が残っているとき、その誕生または初期入口からの有限履歴を保持する。

ここで「良い」は、広い側を左に置いた後の `J(U1,V) ∩ J(U2,V) ≠ ∅`。
**`J` の凸包全体の充填を子に無条件に要求しない。** 必要なのは、現在運んでいる `t` を
含む合法で良い次の被覆が存在すること。

接尾辞だけを28状態に圧縮しても、算術条件を捨ててよいわけではない。
連分数行列、幅比、目標値と過去の比較条件は別に保持する。
特に六つの誕生時接尾辞は同じ構造グラフに写るが、異なる算術領域を持つ。

## なぜ有限履歴になるか

良性から、左の第1・第2分枝間の隙間 `g(U)` は `d(V)` 以下。
原証明の有理評価から

- `d(U2)/g(U) < 187/210 < 1`;
- `d(U11)/g(U) < 11/14 < 1`;
- `d(U3)/g(U) < 11407/20748 < 1`。

従って片側に2または3を付けると必ず広い側が逆転し、1を続けて2回付けても逆転する。
広い印付き側を変更せずに残す操作は、異なる偶奇での `(0,1)` だけ。
これは偶奇を等しくするため連続できない。

グラフの状態は、印のない側の接尾辞、印が313か3131か、両側の偶奇、広い側、
直前の非反転 `(1,0)` の有無。印付き側には、一度だけ `313 -> 3131` の1を許す。
接尾辞が解消する操作はこの局所履歴を終了させる。
上の強制反転を満たす操作をすべて試しても、出力された整数ランクが各辺で減る。
これが有限履歴の帰納を閉じる根拠である。反転に使う良性自体の証明は局所幾何の別義務。
三つの停止制限を一つずつ削除する負の対照試験では、すべて循環を検出して拒否した。

## 目標値の帰納に循環を作らない順序

原証明の `global_selection.tex` に従い、深さ `d` の良い合法な選択履歴から、次の順序で進む。

1. 現在までの履歴とその比較条件から、必要な印付き接尾辞の目標下限を得る。
2. p.97 の例外では、深さ `d-1` での優先選択と、その時点の目標下限だけを使う。
3. 下限を満たす現在の `t` が、残した合法な子被覆のどれかに入ることを局所比較で示す。
4. 指定順でその子を選ぶ。局所比較が子の良性を、語の検査が合法性を与える。

一般誕生の下限は、等偶奇左3131で `C21`、等偶奇右3131で `C22`、異偶奇左3131で `C22`。
異偶奇右3131の該当分枝は不可能。初期履歴の2例外は入口の橋渡しで処理する。
これらの下限は **グラフの有限性だけでは出ない**。今回の数学リプレイの
`targets_bridges` と `suffix_histories` が検査する数値的内容である。

未来の合法性を現在の下限の根拠にしない。この順序なら、過去の選択を仮定する通常の帰納で足りる。
数値区間 `J(U_d,V_d)` が入れ子である必要はない。

## 無限指数についての帰納

`S=313121` とすると

```
M(S) = [[14,19],[53,72]],   M(S)^2 = 86 M(S) - I.
M(3) = [[0,1],[1,3]],      M(3)^2 = 3 M(3) + I.
```

`n≥1` では `M(S)^n = u_n M(S) - u_(n-1) I`、`u_0=0,u_1=1`。
比 `x_n=u_(n-1)/u_n` は `x_1=0`, `x_(n+1)=1/(86-x_n)` を満たす。
区間 `[0,1/85]` の像は `[1/86,85/7309]` に含まれる。
さらに `f(x)=x²-86x+1` について

```
f(1/(86-x)) = f(x)/(86-x)^2,    f(x_1)=1.
```

従って全有限指数で接触因子 `f(x_n)>0`。`n=0` は単位行列として別に扱う。
桁3の反復の比は `y_1=0`, `y_(k+1)=1/(3+y_k)`、区間像は `[3/10,1/3]`。
`k,p` の両方に同じ証明が使える。任意指数の問題は、固定された箱上の算術比較に帰着する。
無限反復の極限は別の明示的周期語として加える。有限の子と極限値を混同しない。

## 無限列への移行

各段階で少なくとも片側が伸び、現在広い側は遅くとも2段以内に伸びる。
片側の語長が有界なら、その側はやがて固定され正の幅を保つ。
他方の語長は発散し幅が0へ行くので、固定側が広くなり、2段以内に伸びることと矛盾する。
従って両側の語長が発散する。

物理的な語の円柱は入れ子であり、禁止語を避ける唯一の両側無限列を定める。
各段階の `t` と極限列の中央値は同じ二つの円柱凸包の和に入る。
その直径は `1/F_(|U|+1)^2 + 1/F_(|V|+1)^2` 以下なので差は0になる。
非中央値の上界と Lagrange スペクトルでの実現は、原証明の別の基礎補題を使う。

## 検証の範囲と未完了事項

`replay_mathematics.py` は原本の算術プログラムを変更せず、宣言済みの実行配置を別領域に再構成する。
数学証明書12群はすべて通過した（通常実行・`-O`・群ごとの負の対照を含む）。
今回の単一ワーカーでの所要時間は1171.104秒。これは現行Pythonでの実測であり、旧式計算機の速度見積もりではない。
結果は `result.json`、進行記録は `replay.log`、群別結果は `logs/`。
短い親 `(31,31)` の例外とその分類・記載内容も `replay_short_parent.py` による独立な再検証を通過した。結果は `short_parent_replay/`。

原本は配布PDFだけが欠け、Finderの `.DS_Store` が2個追加されている。
マニフェストの残り498ファイルにハッシュ変更はなく、リプレイ後も原本は不変。数学部分の結果と配布物一式の検証を区別するため、
完全パッケージ検証・PDF照合の合格とは表示しない。

局所幾何2群だけでも、証明書は22,493本の証明木、116,699件の適用記録を持つ。
入力有理係数の最大ビット長は34、箱の二分深さは最大1。
これは中間整数の大きさや全証明の計算量の上限ではない。
履歴部分の小ささをもって、算術部分まで半世紀前の計算機向けに小さくなったとは主張しない。

新しい Schecker 型探索の保存グラフを閉じた証明書に変換したわけでもない。
その達成には、目標値・優先選択の条件をその検証器の証明義務として表現し、
根の要求区間を原証明の初期系で置き換える／包含を証明する接続が必要。
既存 Freiman 証明の再検証を、この未完成の新証明の完成として数えない。

この接続は形式的な名前の置換では済まない。`check_root_interface.py` で
`(U,V)=(32113,4322)` の全凸包が、同じ接頭語の普通の `J(U,V)` を厳密に含むことを
平方根の有理包囲で確認した。`root_interface.json` には、前者に入り後者に入らない
具体的な有理目標値を保存した。従って `J` 一個への置換は要求範囲を失う。
これは真の Cantor 和集合の隙間の主張ではなく、証明の接続条件の検査である。
