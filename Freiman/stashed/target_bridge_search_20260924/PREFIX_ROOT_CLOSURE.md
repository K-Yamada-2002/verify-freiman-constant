# 全指数の初期区間を閉じた帰納へ接続する

2026-09-24。**探索で要求していた初期族の全凸包を、既存 Freiman 証明の閉じた選択帰納へ接続できた。**
下記はその接続の証明である。元の選択帰納・初期区間の補題を利用するので、
それらに依存しない新しい Schecker 型証明を得た、という主張ではない。

追加部分は1,095個の多項式条件、3,903個の Bernstein 係数で検証した。
二変数それぞれの次数は高々2、保存された係数の分子・分母は最大123ビット。
探索とは異なる実装が、全条件の再構成・係数の符号・Bernstein 展開の恒等式を検査した。
通常実行と `-O` が通過し、6種類の破損証明書を拒否した。

## 主張

外向きの語で `S=313121` とし、

\[
 U_n=3211S^n3,\qquad V_n=4322S^n,\qquad n\ge0
\]

と置く。`K(W)` は固定接頭語 `W` の後に1,2,3だけを追加し、
全体として31313を避ける連分数の集合とする。中央の4を含めて

\[
 \Sigma_n=4+K(U_n)+K(V_n),\qquad I_n=\operatorname{conv}\Sigma_n
\]

と書く。このとき

\[
 \boxed{\Sigma_n=I_n=[c_F,b_n]\quad(n\ge0).}
\]

ここで

\[
 b_n=4+T_{3211S^n33}([0;\overline{131213}])
          +T_{4322S^n}([0;\overline{131312}]).
\]

この等式は、以前の探索で根に置いていた「全指数での全凸包の充填」そのものである。
根より下の探索節点を一つずつ充填済みにすることは、この証明では必要ない。

## 1. 再開に使える被覆

**再開補題。** `(U,V)` が許された固定中央ブロックを保つ物理的接頭語の対で、
両語の長さが4以上、継続比率が `[1/4,4/5]` に入り、いずれも313または3131で終わらないとする。
普通の被覆 `J(U,V)` は非空で良いとする。さらに、偶奇が異なる場合には、
全3桁円柱で広い側が31で終わらないとする。
このとき `J(U,V)` の各目標値は、同じ物理的接頭語を保持する合法な無限継続で実現される。

証明は、既存の [選択帰納](../Freiman_Hall_ray_verification/report/source/staging/parts/global_selection.tex)
をこの被覆から開始することによる。

- 初期時点に313・3131の印がないため、印付き接尾辞の下限を初期仮定にする必要はない。
- 異偶奇での追加条件は、p.97 の「過去の選択から目標下限を得る」例外を開始時点で除く。
  それ以外の開始分枝は、現在の良性と源分枝の比較条件だけで全被覆を処理する。
- 新しく生まれた印には、元の有限履歴補題がそのまま適用できる。
  後の p.97 例外には実在する先行選択がある。
- 語長は減らないので、短い例外 `(31,31)` に到達しない。
  `U=W31` の場合は `W` が非空で、継続比率の下界から元の late-chain 領域条件が従う。
- 同じ目標値を保ち、優先順位を守って選ぶ。元の収縮補題により両側の語長が発散し、
  接頭語を延長する唯一の極限列が目標値を実現する。

以上は「良い被覆は無条件に埋まる」という主張ではない。
初期の印と p.97 の例外を除く条件が必要である。
今回使用する全被覆について、その条件・非空性・両 defining forks の非空性・相互接触を検査している。

今回の全接頭語は `(32113,4322)` を延長する。
この2語の継続比率は `[1/4,4/5]` に入り、
`r -> 1/(a+r)`, `a=1,2,3` は同区間を保つ。従って比率条件もすべての深さで成立する。

## 2. 下側の既存初期系は接頭語を保つ

[既存の初期系](../Freiman_Hall_ray_verification/report/source/staging/parts/lower_core.tex)
にある `A(j,k), B(j,k), C(j,k,p), Bbar(j)` を、`j≥n` に制限する。
これらはすべて、物理的左右を追えば `(U_n,V_n)` を延長する。

固定した `j` の `k,p` の鎖は隣接接触と明示的な周期3の極限でつながる。
`j` 方向の接触と補助区間は隣り合う `j,j+1` をつなぐ。
従って添字の下限を `n` にしても、同じ接触証明で連結な末尾側の系が得られる。
`j→∞` の下端極限は `c_F` である。

[印付き初期入口の橋渡し](../Freiman_Hall_ray_verification/report/source/staging/parts/initial_bridges.tex)
もこの接頭語条件を壊さない。新しい根は元の初期対を延長する。
`C(j,k,1)` の例外が移る先は `B(j,k+2)` で、外側の添字 `j` は変わらない。
Bを優先する選択は、制限後の系の中でも実施できる。
その後は既存の選択帰納が物理的接頭語を保持する。

よって、raw 初期区間 `H(A(n,2))` の上端を `h_n` とすると

\[
 [c_F,h_n]\subset\Sigma_n.
\]

この補題は既存の無限初期系と選択帰納に依存する。有限個の添字を試した結論ではない。
極限の追加は、明示的周期継続またはコンパクトな接頭語和集合 `Σ_n` の閉性で正当化できる。

## 3. 上端への新しい周期帰還

`P=131213`, `Q=131312` と置き、

\[
 B_{n,m}=(3211S^n33P^m,\;4322S^nQ^m),\qquad m\ge0
\]

を考える。これは `(U_n,V_n)` の合法な延長である。
`B_{n,m}` に物理的に `(空語,11)` を追加した普通の被覆を `R_{n,m}` と書く。

今回得た有限鎖は、各 `(n,m)` で `R_{n,m}` と `R_{n,m+1}` をつなぐ。
各鎖の始めは `(空語,11)`、終わりは `(P,Q11)` である。

| 外側の指数 | 上端周期の指数 | 鎖の被覆数 | 厳密条件 |
|---|---|---:|---:|
| `n=0` | `m=0` | 21 | 300 |
| `n=0` | `m≥1` | 21 | 300 |
| `n≥1` | `m=0` | 15 | 218 |
| `n≥1` | `m≥1` | 15 | 218 |

鎖の全ラベルと全比較は `uniform_periodic_strip.json` にある。
各被覆は再開補題の条件を満たす。隣接被覆は両方向の端点比較で交わる。
従って、各鎖の合併は `Σ_n` に含まれる連結な区間で、二つの連続する `R` を含む。

周期行列はいずれもトレース86・行列式1で、
正の固有値は `43+2√462`。`P,Q` の反復はそれぞれ上端の周期末尾を保つ。
`m→∞` で `B_{n,m}` の両円柱幅は0へ行き、各鎖は `b_n` に近づく。
隣の鎖は `R_{n,m+1}` を共有するので、鎖全体の合併は連結である。
`c_n` を `R_{n,0}` の下端とすれば、明示的上端継続も合わせて

\[
 [c_n,b_n]\subset\Sigma_n.
\]

ここでは `B_{n,m}` の全凸包の充填を帰納仮定にしていない。
その全凸包には局所的な隙間がありうる。使うのは、同じ再開被覆を共有する有限鎖だけである。

## 4. 二つの部分をつなぐ全指数の検査

普通の被覆 `J_n=J(U_n,V_n)` 自体が再開補題の条件を満たす。
広い側は3で終わる側であり、異偶奇の初期例外には入らない。
次の接触を `n=0` と `n≥1` の箱で検査した。

\[
 h_n>J_n^-,\qquad J_n^+>R_{n,0}^-,\qquad R_{n,0}^+>J_n^-.
\]

`uniform_root_connection.json` に、29条件と30条件を記録した。
共通の偶数長接頭語 `(3211S^n,4322S^n)` から見た
`h_n` の端点語は `(31331213,331213)`、末尾周期は12である。
これが raw `H(A(n,2))` の上端であることも、初期系の端点定義から直接読める。

下側の区間、`J_n`、上側の区間が接触するので

\[
 [c_F,b_n]\subset\Sigma_n.
\]

逆の包含は円柱極値から従う。`check_endpoint_returns.py` は、
下端が全 `n` で `c_F` に一致し、上端が上記の `b_n` になる周期恒等式と状態遷移を厳密に検査する。
これで主張が証明された。

## 5. 無限指数を有限計算で扱う根拠

三つの周期語 `W=S,P,Q` は、共通の漸化式

\[
 M(W)^k=u_k M(W)-u_{k-1}I,\quad
 u_0=0,\ u_1=1,\ u_{k+1}=86u_k-u_{k-1}
\]

を持つ。`k≥1` で `x_k=u_{k-1}/u_k` とおけば

\[
 x_1=0,\qquad x_{k+1}=1/(86-x_k),\qquad 0\le x_k<1/85.
\]

また `f(x)=x²-86x+1` は

\[
 f(x_{k+1})=f(x_k)/(86-x_k)^2>0
\]

を満たす。従って、実際の有限指数で正の共通行列式因子を消去できる。
検査用の大きい箱の全点で行列式が正だと仮定しているのではない。

外側の `n` と内側の `m` に別々の変数 `x,y` を使う。
行列の正の共通倍率を落とした後、端点の差・幅の比較は、正の分母と共通行列式因子を除けば
各変数2次以下の多項式になる。`[0,1/85]^2` 上の Bernstein 係数の符号で証明する。
端点選択のための幅の大小と `7/5` の短縮条件も証明書に含む。

## 6. 独立検証と計算量

- 生成側: SymPy の代数体と多項式環。
- 検証側: 標準ライブラリの有理数による `Q(√3,√7)` の4係数演算。
- 検証側は、行列・端点規則・必要な比較を独立に再構成する。
- Bernstein 係数から有限差分で元のべき係数を復元し、恒等式として照合する。
- 選んだ全初期被覆の合法性・印の欠如・再開条件を検査する。
- 指数の場合、比較記録、符号、周期鎖の終点、単項式、短縮分岐を破損した6種類をすべて拒否する。

保存係数は最大123ビットなので、固定長の機械整数1個に収まるという意味ではない。
多倍長演算が必要である。一方、追加部分は3,903係数の固定された計算で、
探索の深さや無限指数とともに計算量が増えるものではない。
手元での独立検証の実測は約5.84秒。体の乗算呼出し115,769回、加算64,889回、
反転13,946回、符号判定3,903回だった（内部の重複呼出しを含み、機械命令数ではない）。
詳細は `verification_cost.json` に保存した。
原証明全体を同じ規模へ縮約したわけではなく、1970年代の特定機種での所要時間も未測定。

## 7. 依存関係と現在の到達点

前回の [構造整理](../structural_replay_20260924/STRUCTURAL_INDUCTION.md) で残していた
「全凸包の根を普通の `J` に置換すると目標値を失う」問題を、上の上下二つの接続で解消した。
`J` 一個の置換を正当化したわけではない。

この証明は既存パッケージの次の数学的補題を使用する。

1. 普通の被覆の端点定義と収縮。
2. 局所幾何、優先選択、一般接尾辞履歴による全深さの選択帰納。
3. 無限初期系の接触と、印付き初期入口の橋渡し。

それらの数学証明書12群は前回再検証済みで、原本498ファイルはマニフェストと一致した。
今回の追加証明は原本を変更していない。
配布PDFの欠落は、完全パッケージ・PDF同一性検証の未実施事項として残る。

到達点は、**既存 Freiman 補題に基づく全 `A_n` の接頭語付き全凸包充填**である。
旧探索グラフの全局所型を充填済みと宣言するものではなく、
既存補題に依存しない最小規則の発見も別の課題である。

```sh

python3 -B -O Freiman/target_bridge_search_20260924/verify_uniform_restart.py \
  --output Freiman/target_bridge_search_20260924/independent_uniform_optimized.json
python3 -B -m unittest discover -s Freiman/target_bridge_search_20260924 \
  -p 'test_uniform_controls.py' -v
```
