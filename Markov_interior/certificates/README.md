# Fixed proof certificates

All data required by the default verifier are in this directory:

| Files | Meaning |
|---|---|
| `original.dat`, `original.meta.json`, `original.alive.bin` | `31313` family: 3,464,816 adopted rows out of 4,801,280 |
| `table.dat`, `table.meta.json`, `table.alive.bin` | `31313,13131` family: 4,260,954 adopted rows out of 6,078,592 |
| `roots.json` | 36 original-family extension bands, 25 original-paper bands, and 28 extended-family bands |

The original adoption bytes are unchanged from `graph_wide`. Its state IDs,
prototype words, extension words, interval types and successor candidates are
preserved; numeric geometry is regenerated by the current exact generator in
the same uniform format as the second table. The original Freiman/Lean input
elsewhere in the repository has not been modified.

`roots.json` stores finite words, central digits, bands, state-pair IDs, ratio-box
indices and type IDs. Its endpoints and noncentral bounds are recomputed; it
contains no historical `passed` flag to trust. The supplied root list is a proof
certificate, not a claim that every possible root has been explored.

Run [verify.py](../verify.py) to reproduce both numeric inputs, replay both tables,
and check the complete interval claims using the analytic argument in
[PROOF.md](../PROOF.md). Add `--independent` to also audit input semantics and
coverage with separate implementations. Every file here is a regular file, so
copying the parent directory also copies the complete proof data.
